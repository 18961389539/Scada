# HelloWorld · 智慧工厂学习演示

这份示例展示 Rapid SCADA 的一条完整链路：模拟采集 → 数据服务 → 公式与报警 → 归档 → 网页监控与控制。

## 启动

在项目根目录 PowerShell 中执行：

```powershell
.\tools\Start-Demo.ps1 -Build  # 首次编译、部署并启动
.\tools\Stop-Demo.ps1          # 停止演示
.\tools\Start-Demo.ps1         # 以后直接启动已部署版本
```

打开 <http://127.0.0.1:5000/View/10>。中文总览也可单独打开 <http://127.0.0.1:5000/Demo>。

| 学习账号 | 密码 | 权限 |
|---|---|---|
| admin | 12345 | 监控、控制、报警确认、组态编辑 |
| operator | demo123 | 监控、控制、报警确认 |
| viewer | demo123 | 只读监控与归档查询 |

admin 的密码只初始化在生成的运行数据库中；operator 和 viewer 是本示例专用账号。此处的公开密码用于本地学习。

运行目录为 `.local/HelloWorld`，使用文件存储，无需外部数据库。启动脚本不会注册系统服务；重启电脑后需再次启动。

## 六个动手实验

### 界面操作提示

- 运行画面工具栏提供“适应屏幕”和“100%”；文字较小时切换到 100%，通过滚动查看完整画面。
- 每个运行画面顶部有固定的页面导航，可直接从 A 切换到 B；导航按当前用户的视图权限过滤。
- 储罐页增加设备操作、通信状态和操作记录；总览增加当前报警与历史查询；能耗页增加真实功率归档积分电量，明确显示有效覆盖时间。
- 组件实验室可试用配方和计划：管理员保存参数、操作员可执行有权限的配方；计划仅管理员可管理，默认停用。PID 面板展示实际回路绑定入口，当前演示没有模拟闭环 PID。
- 压力统一使用 bar，总功率量程为 0–7 kW；液位、流量、温湿度与费用按各自单位单独展示趋势。能耗页展示瞬时功率和每小时估算电费，不将功率冒充累计电量。
- 液位与温度按钮标明“模拟设定”，水泵提供明确的启动/停止；发送后等待通道反馈，超时提示结果未知。命令通道的回读不等于独立设备到位反馈。
- 报警列表的“查看并确认”直接打开原生确认窗口；待确认与当前越限分开理解，确认并不使测量恢复。
- 编辑器支持组件搜索、收藏、预览和通道选择器；保存状态常驻工具栏。请先保存，再打开运行预览并刷新。
- 更新本轮界面代码和生成画面可运行 `python .\tools\Generate-MimicPages.py`，再运行 `.\tools\Update-DemoUsability.ps1`。更新脚本先备份运行视图与插件，只重启网页进程；备份位于 `.local/HelloWorld/backups/usability-*`。更新后请刷新运行页，并从铅笔入口重新打开编辑器。

### 编辑器操作补充

- “结构”面板可按组件名称、ID 或类型搜索，显示匹配数量并保留父层级；点击结果选中组件，按 Esc 清空搜索。
- 按 `/` 切到组件面板并聚焦搜索，搜索中按 Esc 清空并返回画布操作；`Ctrl + Shift + Z` 也可重做。编辑输入框或可编辑文本时，Delete 和方向键用于文本操作。
- 通道列表标出已绑定项及 `已绑定数量 / 16`；达到上限后禁用新增项并说明处理方式，重复点击已绑定项不会产生修改。
- 属性“仅已修改”会在值改回默认后立即更新。剪切等待复制完成，复制失败或等待期间切换选区时保留源组件。
- 同步失败会保留本页待提交修改并重试，工具栏显示失败状态；已点击的保存会等更新成功后执行。恢复前请保持编辑页打开。

编辑器专项验证（不发送设备命令）：`node tools/Verify-EditorReliability.cjs` 无需运行服务；`node tools/Verify-EditorUsability.cjs` 需要本地演示已启动、Node 可找到 `playwright-core`，并使用系统 Edge。浏览器验证只修改自动创建的临时组态，结束后关闭并清理；截图位于 `.local/verification/editor-structure-search.png`。

### 1. 先看实时采集

登录后打开运行总览。液位和温度在初始状态缓慢变化，刷新周期约为 1 秒。左侧切到“基础信号实验”，观察数组和波形值。

数据来自 `DrvSimulator`，经 `ScadaComm` 上送至 `ScadaServer`。网页上的读数、历史和事件均来自正在运行的数据服务。

### 2. 运行设备，观察反馈

点击“水泵启停”，在原生命令窗口选择 **On**。稍后出水流量约为 16–20 m³/h、压力约为 2.6–3.0 bar，水泵估算功率为 2.2 kW。

再启动风机，风机功率约为 2.8–3.6 kW。总功率和电费估算随之增加。关停水泵后，流量回到零；关停风机后保留 0.08 kW 待机功率。

命令经过权限检查、数据服务转发和模拟驱动执行，最终以采集数据回传。总览本身不会直接伪造控制结果。

### 3. 做一次报警闭环

1. 点击“液位模拟设定”，输入 **95**，点击“执行命令”。
2. 液位变成高高限，当前报警点数增加，总览与原生组态显示越限状态。
3. 打开“储罐泵站”，在下方原生事件面板找到报警，点击确认入口，完成报警确认。
4. 再把液位设为 **55**，等待状态恢复正常。
5. 用“温度模拟设定”做 **40 → 23** 的同样实验。

| 测量 | 低低限 | 低限 | 高限 | 高高限 | 回差 |
|---|---:|---:|---:|---:|---:|
| 液位 % | 10 | 20 | 80 | 90 | 1 |
| 温度 °C | 10 | 16 | 30 | 36 | 0.5 |

可把液位设为 **5** 观察低低限。越限后，在阈值附近小幅变化还能观察回差如何避免报警反复跳变。

**确认报警**与**恢复正常**是两件事：确认会记录确认人和时间，恢复则需要测量值回到正常范围。

### 4. 查询真实历史和导出报表

等待约 1 分钟，使用总览里的通道和时间范围查询，点击“导出 CSV”。CSV 包含 UTC 时间、通道、名称、数值和状态，可用 Excel 打开。

点击指标卡上的“历史趋势”，打开原生趋势图；点击“查看工艺趋势”可同时查看液位、流量与压力。

到“原生报表”选择历史报表，使用分钟归档 **Min**、通道 **201,301,403** 和今天的时间范围生成报表。原生事件报表用于导出报警与确认记录。原生输出为 Excel 兼容 XML 工作簿，并非 xlsx 格式。

新通道在启动前没有历史数据，查询到空白属于正常情况。不会预填伪造的历史样本。

### 5. 看服务端公式与原生组态

“能耗与公式”页展示连续运行的计算通道：

| 通道 | 计算关系 |
|---|---|
| 401 存水量 | 液位 × 0.8，假定满量程 80 m³ |
| 402 水泵估算功率 | 水泵运行时 2.2 kW，否则为 0 |
| 403 总功率 | 风机功率 + 水泵功率 |
| 404 每小时估算电费 | 总功率 × 0.85 元/kWh |
| 405 当前报警点数 | 液位与温度中处于四种越限状态的点数 |
| 406 联动校验 | 水泵运行且检测到正流量时为 On |

液位与温度支持人工信号注入，方便学习报警；它们不是闭环控制算法。功率、存水量和费用是演示模型的估算值。

admin 点击总览里的“组态编辑器”，可编辑**运行副本**中的 Process.mim。修改后保存，在原生组态页重新打开检查效果。需长期保留的修改应复制回 `Projects/HelloWorld/Views/HelloWorld/Process.mim`。

示例网页和组态编辑器默认使用简体中文，包含属性、工具栏、弹窗和枚举选项。`ScadaWebConfig.xml` 中的 `GeneralOptions/DefaultCulture` 设为 `zh-Hans`；如需英文可改为 `en-GB`，然后以管理员身份重新加载配置。编辑器中文资源同时位于插件的 `lang` 目录和 `LangPack/Chinese-Simplified/ScadaWeb/lang`，部署脚本会自动复制语言包。语言设置不会改写画面中的文字内容或组件类型名。

### 6. 切换角色

退出并用 viewer 登录。能够看实时数据和历史，但总览的控制按钮禁用，也没有编辑器入口。服务端同样拒绝其控制请求。

operator 能控制设备和确认报警，不能使用管理员组态编辑功能。admin 能访问全部本地演示功能。

```text

Projects/HelloWorld/Views/HelloWorld    表格及原生 Process.mim 组态

tools/DemoSetup                        使用原生适配器将 BaseXML 转为 BaseDAT
tools/Start-Demo.ps1                   编译、复制模块并启动三个进程
tools/Verify-Demo.py                   可重复执行的真实集成验收
```

`tools/Enrich-HelloWorld.py` 是已提交示例配置的生成工具。正常运行不需要执行；重新执行会覆盖它管理的示例配置与组态文件。

## 重新部署与验证

修改源码或示例配置后：

```powershell
.\tools\Stop-Demo.ps1
.\tools\Start-Demo.ps1 -Build
python .\tools\Verify-Demo.py
```

`-Build` 会覆盖运行副本里的配置、BaseXML 和视图，保留历史归档。普通启动不会覆盖这些文件。

验证脚本会实际发送模拟控制、触发报警并确认，最后将液位设为 55、温度设为 23，保持水泵和风机运行。验收结果与报表位于 `.local/HelloWorld/verification`。

日志分别位于 `.local/HelloWorld/ScadaServer/Log`、`ScadaComm/Log`、`ScadaWeb/log`。`line001.log` 可看到三台设备的采集和命令执行过程。

储罐泵站底部及组件实验室第 10 节新增联锁与操作许可、故障诊断、报警统计。条件列表使用真实运行反馈作接入示例；控制器最终许可、故障代码和复位策略等待实际设备绑定。报警统计可按次数、持续时间、频繁报警排序并导出 CSV，状态覆盖率不足的时段不会按正常处理。新增接口验收运行 `python tools/Verify-Diagnostics.py`。

组件实验室第 11 节为电气单线图，编辑器“电气单线图”分组提供断路器、隔离开关、接地开关、变压器、母线和连接线。示例全部使用独立组件组成，可调整方向、分合位编码、带电反馈和连接点。电气测点尚未接入时运行图显示未知；编辑预览值不会当成实时值。位置反馈不代表供电状态，带电信号单独绑定。验收：`node tools/Test-ElectricalComponents.cjs`。

此演示覆盖本地开源模块的常用能力；Modbus、MQTT、OPC UA 等真实协议接入需要相应设备或独立模拟服务。高级商业插件和跨节点部署不在本次演示中。
