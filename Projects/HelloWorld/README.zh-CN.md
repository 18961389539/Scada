# HelloWorld · 智慧工厂学习演示

这份示例展示 Rapid SCADA 的一条完整链路：模拟采集 → 数据服务 → 公式与报警 → 归档 → 网页监控与控制。

## 启动

演示的启停脚本已随 `tools/` 目录一并移除。手工启动需先构建 `ScadaServer`、`ScadaComm`、`ScadaWeb` 三个解决方案，再把 `Projects/HelloWorld/Instances/Default` 下的同名配置目录复制到各自运行目录，然后依次启动这三个应用。

打开 <http://127.0.0.1:5000/View/10>。中文总览也可单独打开 <http://127.0.0.1:5000/Demo>。

| 学习账号 | 密码 | 权限 |
|---|---|---|
| admin | 12345 | 监控、控制、报警确认、组态编辑 |
| operator | demo123 | 监控、控制、报警确认 |
| viewer | demo123 | 只读监控与归档查询 |

admin 的密码只初始化在生成的运行数据库中；operator 和 viewer 是本示例专用账号。此处的公开密码用于本地学习。

运行目录为 `.local/HelloWorld`，使用文件存储，无需外部数据库。上述进程不会注册为系统服务；重启电脑后需再次启动。

## 可以体验什么

| 入口 | 展示能力 |
|---|---|
| 01 运行总览 | 中文实时指标、动态储罐水位、水泵和风机动画、实时功率、报警状态、历史查询和 CSV 导出 |
| 02 原生工艺组态 | Mimic 插件的通道绑定、数值颜色、曲线动作、命令动作、缩放 |
| 03 储罐泵站 | 液位、流量、压力、启停命令、模拟设定和三元素数组 |
| 04 空调机组 | 温度、湿度、风机功率、启停命令和模拟设定 |
| 05 能耗与公式 | 存水量、总功率、估算电费、当前报警数、泵与流量联动校验 |
| 06 基础信号实验 | 原始正弦波、方波、三角波、继电器和随机数组 |
| 07 工业组件实验室 | 20 种新增组件：工艺设备、量程显示、输入控制、真实趋势、数据表、事件和图形 |
| 原生报表 | 历史数据报表、事件报表、表格导出，输出 Excel 兼容 XML 工作簿 |
| 组态编辑器 | admin 可打开部署副本中的 Process.mim，在浏览器中编辑和保存 |

共 3 个模拟设备、4 个对象、24 条通道定义（数组展开后为 30 个数据点）、8 个视图条目，启用 7 个 Web 插件。在线编辑器共提供 26 种组件，详细操作见 `ScadaWeb/Mimics/PlgMimBasicComp/README.zh-CN.md`。组件展示入口为 <http://127.0.0.1:5000/View/24>。

总览是独立的 `PlgHelloWorld` Razor Pages 插件，读取项目原生数据接口；控制、报警确认、报表和组态编辑继续使用原生模块。

## 六个动手实验

### 1. 先看实时采集

登录后打开运行总览。液位和温度在初始状态缓慢变化，刷新周期约为 1 秒。左侧切到“基础信号实验”，观察数组和波形值。

数据来自 `DrvSimulator`，经 `ScadaComm` 上送至 `ScadaServer`。网页上的读数、历史和事件均来自正在运行的数据服务。

### 2. 运行设备，观察反馈

点击“水泵启停”，在原生命令窗口选择 **On**。稍后出水流量约为 16–20 m³/h、压力约为 2.6–3.0 bar，水泵估算功率为 2.2 kW。

再启动风机，风机功率约为 2.8–3.6 kW。总功率和电费估算随之增加。关停水泵后，流量回到零；关停风机后保留 0.08 kW 待机功率。

命令经过权限检查、数据服务转发和模拟驱动执行，最终以采集数据回传。总览本身不会直接伪造控制结果。

### 3. 做一次报警闭环

1. 点击“液位模拟设定”，输入 **95**，点击“执行命令”。
2. 液位变成高高限，当前报警点数增加，总览与原生组态显示越限状态。
3. 打开“储罐泵站”，在下方原生事件面板找到报警，点击确认入口，完成报警确认。
4. 再把液位设为 **55**，等待状态恢复正常。
5. 用“温度模拟设定”做 **40 → 23** 的同样实验。

| 测量 | 低低限 | 低限 | 高限 | 高高限 | 回差 |
|---|---:|---:|---:|---:|---:|
| 液位 % | 10 | 20 | 80 | 90 | 1 |
| 温度 °C | 10 | 16 | 30 | 36 | 0.5 |

可把液位设为 **5** 观察低低限。越限后，在阈值附近小幅变化还能观察回差如何避免报警反复跳变。

**确认报警**与**恢复正常**是两件事：确认会记录确认人和时间，恢复则需要测量值回到正常范围。

### 4. 查询真实历史和导出报表

等待约 1 分钟，使用总览里的通道和时间范围查询，点击“导出 CSV”。CSV 包含 UTC 时间、通道、名称、数值和状态，可用 Excel 打开。

点击指标卡上的“历史趋势”，打开原生趋势图；点击“查看工艺趋势”可同时查看液位、流量与压力。

到“原生报表”选择历史报表，使用分钟归档 **Min**、通道 **201,301,403** 和今天的时间范围生成报表。原生事件报表用于导出报警与确认记录。原生输出为 Excel 兼容 XML 工作簿，并非 xlsx 格式。

新通道在启动前没有历史数据，查询到空白属于正常情况。不会预填伪造的历史样本。

### 5. 看服务端公式与原生组态

“能耗与公式”页展示连续运行的计算通道：

| 通道 | 计算关系 |
|---|---|
| 401 存水量 | 液位 × 0.8，假定满量程 80 m³ |
| 402 水泵估算功率 | 水泵运行时 2.2 kW，否则为 0 |
| 403 总功率 | 风机功率 + 水泵功率 |
| 404 每小时估算电费 | 总功率 × 0.85 元/kWh |
| 405 当前报警点数 | 液位与温度中处于四种越限状态的点数 |
| 406 联动校验 | 水泵运行且检测到正流量时为 On |

液位与温度支持人工信号注入，方便学习报警；它们不是闭环控制算法。功率、存水量和费用是演示模型的估算值。

admin 点击总览里的“组态编辑器”，可编辑**运行副本**中的 Process.mim。修改后保存，在原生组态页重新打开检查效果。需长期保留的修改应复制回 `Projects/HelloWorld/Views/HelloWorld/Process.mim`。

示例网页和组态编辑器默认使用简体中文，包含属性、工具栏、弹窗和枚举选项。`ScadaWebConfig.xml` 中的 `GeneralOptions/DefaultCulture` 设为 `zh-Hans`；如需英文可改为 `en-GB`，然后以管理员身份重新加载配置。编辑器中文资源同时位于插件的 `lang` 目录和 `LangPack/Chinese-Simplified/ScadaWeb/lang`；部署时需把后者手工复制到 Web 的 `lang` 目录。语言设置不会改写画面中的文字内容或组件类型名。

### 6. 切换角色

退出并用 viewer 登录。能够看实时数据和历史，但总览的控制按钮禁用，也没有编辑器入口。服务端同样拒绝其控制请求。

operator 能控制设备和确认报警，不能使用管理员组态编辑功能。admin 能访问全部本地演示功能。

## 重新部署与验证

原 `tools/` 下的 `Stop-Demo.ps1`、`Start-Demo.ps1 -Build`、`Verify-Demo.py` 已随该目录移除，本节不再提供自动化流程。重新部署时需手工覆盖运行副本中的配置、BaseXML 与视图；历史验收产物（如曾生成）保留在 `.local/HelloWorld/verification`。

日志分别位于 `.local/HelloWorld/ScadaServer/Log`、`ScadaComm/Log`、`ScadaWeb/log`。`line001.log` 可看到三台设备的采集和命令执行过程。

此演示覆盖本地开源模块的常用能力；Modbus、MQTT、OPC UA 等真实协议接入需要相应设备或独立模拟服务。高级商业插件和跨节点部署不在本次演示中。
