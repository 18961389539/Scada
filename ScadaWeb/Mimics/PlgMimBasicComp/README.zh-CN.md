# 基础与工业组件库

本插件在原有按钮、指示灯、开关之外提供 73 种工业组件。加上 Mimic 内置的文字、图片、面板，在线编辑器共可使用 **79 种组件**。

### 电气单线图

“电气单线图”分组新增 6 种独立组件，在组件实验室第 11 节提供可编辑的进线、变压器、母线、馈线和接地支路示例。

| 组件 | 输入与状态 |
| --- | --- |
| `IndustrialCircuitBreaker` 断路器 | `inCnlNum` 位置反馈：默认 0 分闸、1 合闸、2 跳闸；`energizedChannel` 单独读取带电反馈；可选 `tripChannel` 跳闸信号（1 跳闸、0 未跳闸），配置后优先于位置中的跳闸编码。 |
| `IndustrialDisconnector` 隔离开关 | `inCnlNum` 分合位反馈、`energizedChannel` 独立带电反馈，显示明确的刀闸断口。 |
| `IndustrialGroundSwitch` 接地开关 | 同样分别读取分合位和带电状态，带固定接地符号。 |
| `IndustrialTransformer` 变压器 | `inCnlNum` 为带电状态信号，双绕组图形。 |
| `IndustrialBusbar` 母线 | `inCnlNum` 为带电状态信号；支持横向或纵向、线宽和颜色。 |
| `IndustrialElectricalLine` 电气连接线 | `inCnlNum` 为带电状态信号；`route` 支持 `straight` 直线、`elbow` 直角、`tee` 三通；`showJunction` 显示中心连接点。 |

开关位置默认红色合闸、绿色分闸、黄色跳闸。导线带电颜色取决于独立带电反馈，不从开关位置推断；带电反馈默认 1 带电、0 无电反馈，可用 `energizedValue` / `deenergizedValue` 调整。未绑定、不在编码映射内、质量无效或读取超过 15 秒未更新，显示灰色虚线和未知；跳闸反馈无效会单独提示。编辑器中的 `value` 和 `previewEnergized` 只用于预览，不会作为运行值。

双点位置反馈可配置 `openValue=1`、`closedValue=2`、`tripValue=-1`（断路器），使 0 / 3 均显示位置未知；有独立跳闸测点时填入 `tripChannel`。不要把物理电压值直接绑定到 0/1 带电信号，应由采集或服务端生成带电状态点。

`vertical` 控制方向；`showLabel`、`showState` 和 `labelPosition`（right/left/top/bottom）控制标注。竖向开关/变压器的端点位于组件上、下边缘中心，横向位于左、右边缘中心；母线与连接线按中心线连接。连接点需显式标注，图形连接不会自动计算拓扑、传播电位或执行闭锁。电气组件默认无输出通道、无点击命令；需要控制时在组态中配置原生命令窗口，设备操作联锁由 PLC 或服务端实施。

新增组件继承原有权限和通道选择器，支持保存重开和中英俄名称。当前演示没有电气设备测点，运行图保持未知状态；编辑器提供分合位预览，未将水泵或风机反馈冒充电气数据。

运行 `node tools/Test-ElectricalComponents.cjs` 验证分合位与带电独立性、跳闸优先级、双点编码、无效/过期数据、横向图形、连接点和 HTML 转义。

### 联锁、故障与报警分析

新增组件位于“报警与状态”分组。储罐泵站和组件实验室第 10 节可直接查看。

| 组件 | 绑定和行为 |
| --- | --- |
| `IndustrialInterlockPanel` 联锁与操作许可 | `channels` 条件通道、`labels` 名称、`expectedValues` 对应期望值（留空均为 1）、`permitChannel` 控制器最终许可。0 表示未绑定，许可通道有效且值为 1 才显示允许；其他有效值显示闭锁，无效值显示未知。条件匹配不生成最终许可。 |
| `IndustrialFaultDiagnostics` 故障诊断面板 | `faultChannel` 读取设备整数故障代码，0=无故障；未绑定/数据异常显示未知。`faultDefinitions` 配置说明和处理建议，未知代码提示查看手册。`policyId` 对应服务端复位策略，策略缺失时按钮禁用。 |
| `IndustrialAlarmStatistics` 报警统计与排行 | `channels`、`archiveBit`（默认 4）、`historyMinutes`（默认 1440）、`maxRows`。支持最长 7 天查询、次数/持续时间/频繁报警排序，CSV 导出所有结果和统计完整性。 |

故障说明按设备手册填写，例如：

```json
{"7":{"description":"电机过载","action":"检查机械负载、热继电器及驱动器记录"}}
```

服务端复位策略位于 Webstation 的 `storage/industrial-diagnostics.json`，格式参见本目录 `industrial-diagnostics.example.json`。该模板所有通道均为 0，须由部署管理员替换为实际控制器通道，不会随演示部署自动启用。策略包含唯一 `id`、`faultChannel`、允许复位的 `resetAllowedCodes`、固定 `reset` 命令和 `conditions` 许可条件。通道权限、全局命令开关、故障代码、数据质量和许可条件在服务端校验，并在发送前再次检查。请求正文只接受策略编号，无法覆盖输出通道和命令值；复位记录操作人和回读结果。

`reset.feedbackChannel` 是用于确认命令值的反馈点。复位脉冲应由控制器完成脉冲处理并提供确认反馈，不能直接使用期望归零的故障代码作为“值 1 已接收”的反馈。命令确认后诊断面板重新读取故障代码，仍有故障时继续显示故障。页面许可面板提供状态解释；设备侧最终联锁仍由 PLC 或控制系统执行。

报警统计以 11/12/14/15 为越限。连续越限过程中等级变化单列，不增加发生次数；恢复后再次越限才算新发生。距前次发生不超过 60 秒记为一次频繁报警。查询开始前最多回溯 7 天查找起始状态；没有起始记录的时间、无效质量区间不计入持续时间，表中单独显示状态覆盖率。跨窗口报警只累计窗口内的持续时间。归档必须记录状态/质量变化，否则事件统计无法识别未记录的采集间断。读取达到 20,000 条事件上限时，次数标为下界、持续时间隐藏，需缩短时段或限定通道后重新查询。

当前演示没有真实 PLC 最终许可及故障代码，因此最终许可与故障面板保持“待接入/未知”，不以水泵、风机的运行反馈冒充许可或故障。报警统计读取实际液位、温度事件。

新增验证：`python tools/Verify-Diagnostics.py` 覆盖实际事件发生/恢复、只读权限、复位策略和联锁校验、篡改输出拒绝、复位审计及测试数据恢复。

## 运行流程组件

所有原生运行画面顶部都显示按当前用户权限过滤的导航栏，当前画面高亮。可直接从总览切换到储罐、空调、能耗或组件实验室；完整入口为 `/View/编号`，独立 `/Mimic/MimicView/编号` 同样带导航。新增组件示例位于实验室第 07–09 节。

| 组件 | 配置与行为 |
|---|---|
| 页面导航栏 | 留空“导航视图编号列表”显示所有可访问视图；填写 `10,21,22,23` 限定入口。 |
| 导航／返回按钮 | 设置“目标视图编号”；返回按钮优先返回本浏览器会话的上一运行画面，无记录时使用目标视图。 |
| 设备操作面板 | 通道列表显示实际反馈；“输出通道”与“反馈通道”用于启停或数值设定，量程和步长参与校验。通道回读与独立设备到位信号需按实际设备分别绑定。 |
| 当前报警表 | 按当前通道状态筛选四级越限，支持“仅待确认”和设备画面定位；在最近 7 天、最多 5000 条相关事件中匹配当前状态的最新事件，通过原生确认窗口记录确认人。正常恢复后从此表消失，历史事件仍保留。 |
| 历史查询工具条 | 支持本地日期时间、最近一小时／一天、通道选择、最长 7 天查询；表格行数可限制，CSV 导出完整查询结果，时间明确为 UTC。 |
| 通信状态卡 | 显示通道数据质量和最后成功读取时间；可另绑“设备在线状态通道”（大于 0 为在线）。未配置在线信号时不会把 API 可读冒充设备在线；读取时间不等于实际采样时间。 |
| 操作记录表 | 查询原生 API 命令、配方、计划的用户、时间、原值、目标值及结果。服务端保留最近 2000 条，单次查询最多返回 200 条。网页命令表单产生的原生事件仍可在事件报表查询。 |
| 配方与参数组 | 管理员保存最多 8 个输出参数及反馈、范围、步长、容差；有控制权限的用户可执行。服务端先校验全部参数与权限，再逐项发送和等待反馈；一项失败或反馈未知时停止后续参数，显示部分执行结果，不自动回滚或重发。 |
| 计划运行 | 管理员保存单次或按星期重复的计划，默认停用；星期用 `0,1,…,6`，0=周日。按浏览器时区保存，关闭浏览器后由服务端运行。执行前再次检查所有者仍启用且为管理员、通道与命令权限；错过超过一分钟的执行跳过，命令派发前持久化认领，重启不重发同一时次。 |
| 选项卡容器 | 容器内子组件的“CSS 类”填写 `tab-1`、`tab-2`…；未指定类的子组件在各页共享。编辑模式显示全部子组件；运行时按选项卡切换。 |
| 折叠容器 | 可放入其他组件，设置初始折叠状态；运行时点击标题展开或收起。 |
| PID 回路面板 | 绑定 PV 过程值、SP 设定反馈、MV 输出反馈、模式反馈及相应命令通道。模式约定 0=手动、1=自动；提供设定和模式操作。实际 PID 算法由控制器执行；示例没有伪造 PID 闭环，未绑定的命令按钮禁用。 |

配方、计划与操作记录保存于网页运行目录 `storage/industrial-operations.json`，使用原子文件替换。所有写接口验证登录、权限及防伪令牌；浏览器不保存计划执行状态。配方不是多通道原子事务。

原有“报警确认”组件已改为选择真实待确认事件并打开原生确认窗口，不再向普通输出通道写入 1。“电能表”可直接绑定电量通道；启用“按功率归档积分”时输入通道必须为 kW/W，按归档连续有效区间做梯形积分并显示实际覆盖分钟数；超过 3 分钟的缺口不补值。多通道趋势支持各曲线单位、最小／最大值、采样点读数和运行时缩短／扩大时间范围。

## 学习入口

启动 HelloWorld 演示后打开 `http://127.0.0.1:5000/View/24`，或从总览进入“工业组件实验室”。原生独立画面地址为 `http://127.0.0.1:5000/Mimic/MimicView/24`。

管理员在“组态编辑器 → 已打开的组态画面”中，打开运行目录下的 `Views/HelloWorld/Components.mim`，即可查看所有新组件的配置；原有 `Process.mim` 不受展示画面生成工具影响。

添加组件的方式沿用原编辑器：在左侧点击组件，再在画布点击放置；选中后进入“属性”设置位置、尺寸、外观与数据。保存后在运行画面重新打开。

左侧支持按名称或类型搜索组件，☆ 收藏保存在当前浏览器，支持“仅显示收藏”。选择组件后可看到真实组件的编辑预览，按 Esc 取消放置。选中画布里的一个组件后，工具栏的“绑定通道”可按名称、编号、单位搜索输入/输出通道；只列出适合该属性的通道，输入绑定同时采用通道单位。通道列表按点击顺序追加，最多 16 个；需要时在属性中调整对应名称列表。

工具栏显示未保存、保存成功时间和保存失败；“预览运行画面”打开对应运行页，预览前请先保存并刷新。保存说明解释 HelloWorld 运行副本与项目文件的关系。

## 数据与操作设置

- **单通道组件**：设置“输入通道”，运行时自动取该通道数值。仪表、液位、储罐、进度条可设置最小值、最大值、单位和小数位数。无效数据会显示“无数据”，不会当作有效的零值。
- **设备与管道**：输入值大于“运行判定阈值”时使用运行颜色，低于或等于阈值使用停止颜色；标准越限状态使用报警颜色。水泵和风机支持运行动画，管道支持流动动画。动画可关闭，并尊重浏览器的减少动态效果设置。
- **设备命令**：水泵、阀门、风机、电机的默认单击动作为原生命令对话框。设置“输出通道”后可操作；阀门、电机在演示中只跟随现有模拟信号，没有另外模拟真实执行器。
- **数值输入、下拉框、滑块**：设置输入通道用于反馈，输出通道用于发送。修改后点击“发送”才下发，校验量程、步长和选项值。`viewer` 控件禁用，服务端继续执行原有控制权限检查。编辑期间保留待发送值，实时刷新不会覆盖用户正在输入的内容。
- **下拉框选项**：使用 `停止=0;启动=1` 这样的“名称=数值”格式，并将量程设为包含全部选项的范围。
- **数据表格和状态灯组**：在“通道列表”填写 `201,202,301,403`，在“名称列表”填写对应名称，用逗号分隔。最多 16 个通道。每 5 秒更新；服务器按当前用户权限读取数据。额外通道不会自动加入原生“视图事件”的过滤列表。
- **趋势图**：设置输入通道、归档位号（HelloWorld 分钟归档为 `1`）、历史时长（1–1440 分钟）和纵轴量程。每 30 秒查询真实历史，按时间坐标绘制，无效采样保留断点；没有归档数据时显示提示。单击动作还可配置为打开原生趋势窗口。
- **报警列表**：HelloWorld 事件归档位号为 `4`；读取当前用户可见的最近两天事件，包括报警、恢复和命令记录。可按通道列表筛选，显示当前可见事件的待确认数量。“查看并确认”直接打开原生确认窗口，关闭后刷新事件；权限与确认人记录沿用服务端原有检查。列表并不是“当前未恢复报警”清单，确认不代表测量恢复正常。

**命令反馈**：输入、按钮组、选择及保护开关在发送后等待绑定输入通道的有效回读；没有输入绑定时回读输出通道。相同输出通道等待期间阻止重复发送。15 秒内未取得匹配反馈则提示“反馈超时，执行结果未知”，不会自动重发；发送失败保留待发送值。输入/输出相同的“命令通道回读已确认”只表示通道值匹配，不表示另有独立设备到位信号。模拟液位与温度控件分别回读采集通道 201、301。

单通道趋势显示起止时间，悬停采样点可查看时间、数值和单位，键盘可聚焦采样点。无效数据保留断点。超出量程时仪表保留实际读数并额外提示，不把裁剪后的刻度当成测量上限。

编辑器中的图表、表格和事件使用标注了“编辑预览”的示意内容；运行画面读取真实数据。输入控件在编辑器中不会发送命令。

## 悬停提示（Tooltip）

组件属性“Tooltip”在运行画面由自定义气泡渲染，不再是浏览器原生 `title`：

- 支持多行，属性里直接回车换行即可；空值不显示气泡。
- 悬停约 120 ms 后出现，位置自动避开视口边缘，超出上方空间时翻转到组件下方。
- 键盘聚焦同样触发，`Esc` 关闭；触摸设备长按 400 ms 显示，滚动时自动收起。
- 气泡内容通过 `textContent` 写入并设置 `aria-describedby`，不会被当作 HTML 执行。
- 编辑画布不绑定气泡，避免遮挡拖拽；编辑器内仍保留原生 `title` 便于快速查看。
- 展示画面 `Components.mim` 的 20 个工业组件均已配置示例说明。

实现位于 `industrial.js` 的 `bindTooltip` / `placeTooltip`，样式为 `industrial.css` 中的 `.ic-tooltip`。其他插件可复用 `rs.mimic.IndustrialTooltip.bind(elem, component, context)`。
