# 采集诊断

管理员进入“设备配置”，点击设备行的“采集诊断”。诊断复用正在运行的采集任务，不创建额外的 PLC 轮询连接。默认每 3 秒刷新，可暂停或手动刷新。

远程设备的查询、分页、导出及重连在所属网关执行，页面标明网关编号和实际配置摘要。网关须在线并确认当前配置；旧版不支持、离线或配置未确认时明确拒绝，不改用中心驱动。在线请求、权限与超时边界见 [远程工程操作](remote-engineering.md)。

中心另根据当前心跳、采样及租约生成 [网关设备离线报警](gateway-device-alarms.md)。诊断中的变量 Bad 质量与设备通信离线分别判断；配置性停采不会冒充通信恢复。

## 状态与统计

- 设备状态区分停用、没有测点、等待采集、正常、部分测点异常、离线和任务异常停止。连接建立且读取调用成功，不代表每个测点质量正常。
- 当前操作显示连接、读取、写入及回读或空闲；写入时标出测点 ID，命令队列显示实际待处理数量，上限 128。
- 连接尝试/失败与轮询尝试/成功/失败分别计数。单点坏质量计入“质量异常批次”，不当作整批通信失败。尚未完成或被取消的读取不计成功。
- 耗时窗口包含最近最多 120 个完成的轮询批次，显示平均、最大和 P95（排序后取向上取整的第 95 百分位位置）。正常批次耗时测量驱动读取调用；异常批次记录从读取开始到异常被捕获的耗时。
- 显示最近读取尝试、成功、通信失败、错误原因和预计重试时间。连接失败使用 1、2、4…最大 30 秒退避；读取失败后的等待取采集周期与退避值较大者。连接成功但读取继续失败不会重置退避，成功读取后才重置。
- 配置变化等待重建时显示提示。统计、120 批采样及最近 200 条事件属于当前采集任务，任务重建或进程重启后重新计数，不是持久审计记录。

## 测点与读取分组

测点表显示实际地址、数据类型、原始值、工程量、质量、采样龄期和错误。展开行可查看源时间、最近正常时间及完整 NodeId。支持按名称/地址/ID 搜索、质量筛选、仅看过期及每页 25～200 条。

驱动没有返回某个配置测点时，该点标记为 Bad，原因是“本次读取未返回该测点”；工程量换算溢出也明确标坏。异常质量保留最近值，当前任务从未取得正常值时，诊断表的工程量显示为空。判断数据可用性时必须同时查看质量和龄期。

过期阈值为 `max(3000 ms, 3 × 采集周期, 采集周期 + 超时)`，龄期从采集服务最近一次更新该点的时间计算。过期与质量分别判断：一个停止更新的 Good 点仍可显示“正常 · 过期”。源时间由协议提供，不用于代替采集服务的龄期判断；没有源时间的协议显示为空。

读取分组对应实际读取计划。Modbus 显示功能区、起始地址、位/寄存器长度和测点 ID；S7 显示区域、DB、字节范围和测点；OPC UA 按实际最多 100 节点一批显示。错误事件包含驱动返回的异常信息，但本界面不保存原始网络报文或串口字节流。

## 重连与导出

“请求重连”在当前轮询和已经排队的命令处理结束后执行，不中断正在写入的命令，也不自动重发。请求后到执行重连期间拒绝新写入。停用设备和没有测点的设备不能请求重连；任务异常停止时请求会触发任务重建。管理员请求写入配置数据库操作日志。

配置已变化但采集任务尚未重建时，也拒绝新写入，避免把新地址配置用于旧的采集连接。重连不能替代现场独立动作反馈；命令超时仍需按结果未知处理。

“导出诊断”下载设备的完整 JSON 快照，包含全部测点，不受当前表格筛选或分页限制；包含连接地址、读取分组、统计、采样和事件。快照不序列化 Device 实体，不包含 OPC 用户名、密码、密文、私钥或登录令牌。它只覆盖当前设备运行诊断，不是项目备份或完整运维诊断包。

## 接口与权限

以下接口仅管理员可用，并禁止缓存诊断响应：

| 方法与路径 | 行为 |
|---|---|
| `GET /api/devices/{id}/diagnostics` | 运行快照；`page` 默认 1、`pageSize` 默认 100，上限 200；可选 `search`、`quality`、`staleOnly` |
| `GET /api/devices/{id}/diagnostics/export` | 完整 JSON 文件 |
| `POST /api/devices/{id}/diagnostics/reconnect` | 202 表示请求已接收，实际执行见后续事件；不可执行返回 409 |

普通查看员/操作员不能读取诊断、导出或请求重连。设备不存在返回 404，非法查询参数返回 400。

## 验证范围

自动测试覆盖连接失败和读取失败的区分、遗漏测点标坏、最近正常值与原始值、源时间戳、过期数据、配置重载期间拒绝写入、命令队列过期、在途写入与重连串行、清空测点后移除旧在线状态，以及 API 分页、筛选、权限、导出内容和浏览器操作。OPC 场景使用真正 SDK 服务器的 TCP 连接。

这属于第 3 项的采集诊断交付。远程诊断另由真实独立网关及 OPC 服务器验证；网关其余功能、真实硬件、长稳与规模验收仍按路线图推进。
