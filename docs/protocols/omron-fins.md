# 欧姆龙 FINS

驱动：`Scada.Collector.Omron.OmronFinsDriver`，自研实现。适用于 CS/CJ/CP/NJ/NX 系列的 FINS 以太网端口（默认 9600）。

## 设备参数

| 字段 | 默认 | 说明 |
|------|------|------|
| `transport` | `Udp` | `Udp` / `Tcp`（FINS/TCP 含节点号握手） |
| `destNetwork` / `destNode` / `destUnit` | 0 / 0 / 0 | PLC 的 FINS 地址；UDP 下 `destNode` 必填（通常为 PLC IP 末段），TCP 为 0 时采用握手返回的服务器节点号；`destUnit` 0 为 CPU |
| `sourceNetwork` / `sourceNode` | 0 / 0 | 本机 FINS 地址；UDP 下必填且同一网络内唯一（与 PLC 的 IP 地址表/自动转换方式一致），TCP 为 0 时由 PLC 自动分配 |
| `highWordFirst` | false | 32/64 位值字顺序；欧姆龙 DINT/REAL 默认低字在前 |
| `maxGap` | 16 | 批量读合并空隙（字） |

## 地址语法

`区域 + 十进制字地址[.位]`：

| 区域 | 写法 | 字区域码 / 位区域码 |
|------|------|------|
| CIO | `CIO10`、`CIO10.05` | B0 / 30 |
| 工作区 WR | `W3`、`W3.00`（或 `WR`） | B1 / 31 |
| 保持区 HR | `H10`（或 `HR`） | B2 / 32 |
| 辅助区 AR | `A100`（或 `AR`） | B3 / 33 |
| 数据区 DM | `D100`（或 `DM`） | 82 / 02 |
| 定时器当前值 | `T5`（或 `TIM`） | 89 |
| 计数器当前值 | `CNT5` | 89（偏移 0x8000） |

- 带位号的测点为 Bool；不带位号时可用 Int16/UInt16/Int32/UInt32/Float/Double。
- 位写入使用位区域码，PLC 原子执行，不影响同字其他位。
- 暂不支持 EM 扩展区、定时器/计数器完成标志、DR/IR、任务标志。

## 读写与错误

- 命令 0101（内存区读）/0102（内存区写）。按区域码合并（单次 ≤499 字），位测点读取所在字后取位。
- 校验应答 SID、路由与命令码；结束代码屏蔽中继错误与 CPU 致命/非致命标志位后判定，非零则该区段测点 Bad（含代码说明），连接保持。
- 超时关闭连接，由采集引擎退避重连；写入超时报告“结果未知”，不重发。
- FINS/TCP 握手失败（如节点号重复 0x24、连接占满 0x20）会在连接错误中给出说明。

## 限制

- 测试使用自研模拟器；**未连接真实欧姆龙 PLC 验证**。NJ/NX 需在 PLC 中把变量分配到 CIO/DM 等内存区才能经 FINS 访问。
- 不支持 FINS 网关路由多跳的自动配置（可手工设置网络号），不支持 Host Link（串口 FINS）。
