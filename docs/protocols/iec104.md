# IEC 60870-5-104 主站

驱动：`Scada.Collector.Iec104.Iec104Driver`，**自研实现**。未使用 lib60870.NET：其许可为 GPLv3/商业双许可，引入会使产品整体受 GPL 约束。

## 设备参数

| 字段 | 默认 | 说明 |
|------|------|------|
| `commonAddress` | 1 | ASDU 公共地址（1～65534）；其他公共地址的 ASDU 忽略，65535 广播接受 |
| `originatorAddress` | 0 | 源发地址 |
| `t1Sec`/`t2Sec`/`t3Sec` | 15/10/20 | 发送/测试确认超时、接收确认延迟、空闲测试；要求 t2 < t1 |
| `k`/`w` | 12/8 | 未确认发送上限、接收多少 I 帧后发送 S 帧；要求 w ≤ 2k/3 |
| `giIntervalSec` | 900 | 周期总召唤；0 = 仅连接后与收到“初始化结束”（M_EI_NA_1）时召唤 |
| `counterIntervalSec` | 0 | 周期电度量召唤（C_CI_NA_1，QCC=5 总请求）；0 = 不召唤 |
| `clockSync` | true | 连接后发送 C_CS_NA_1 对时 |
| `deviceTimeUtc` | true | CP56Time2a 时标按 UTC 解释（false 按服务器本地时区） |
| `commandMode` | `SelectExecute` | `SelectExecute`（SBO）或 `Direct` |
| `waitActTerm` | true | 命令 ACTCON 之后等待 ACTTERM |

连接超时 t0 使用设备“超时”；每一步命令确认等待也使用设备“超时”。

## 测点地址

```
M_<类型>:<IOA>[;cmd=C_<命令>:<IOA>][;sbo=0|1]
```

| 地址类型 | 接受的 ASDU | 数值 |
|----------|-------------|------|
| `M_SP` | 1、30 | 0/1，须为 Bool |
| `M_DP` | 3、31 | Bool：开=1、合=0，DPI 0/3（中间/不确定）为 Bad；数值类型给出原始 DPI 0～3 |
| `M_ME_NA` | 9、34、21 | 归一化值 −1～1 |
| `M_ME_NB` | 11、35 | 标度化值（Int16） |
| `M_ME_NC` | 13、36 | 短浮点 |
| `M_IT` | 15、37 | 累计量（Int32） |
| `M_ST` | 5、32 | 步位置（−64～63） |
| `M_BO` | 7、33 | 32 位串 |

命令：`C_SC`（45，单点，Bool）、`C_DC`（46，双点，Bool：1=合 ON/DCO=2，0=分 OFF/DCO=1）、`C_SE_NA`（48，归一化 −1～0.99997）、`C_SE_NB`（49，标度化）、`C_SE_NC`（50，浮点）。命令 IOA 与反馈 IOA 分开配置，例如断路器 `M_DP:2001;cmd=C_DC:6001`。

## 品质与时标

| QDS/SIQ/DIQ 位 | 质量 |
|----------------|------|
| IV | Bad（“无效（IV）”） |
| NT | Uncertain |
| SB | Uncertain |
| BL | Uncertain |
| OV（测量值） | Uncertain |
| 累计量 IV / CA | Bad / Uncertain |

带时标类型（30～37）用 CP56Time2a 作源时间戳（IV 位或非法日期时改用接收时间）；无时标类型用接收时间。未收到的点：总召唤完成前为“等待总召唤完成”，之后为“子站未上送该信息对象”。

## 链路管理

- 连接后 STARTDT（t1 内未确认则失败）→ 对时 → 总召唤 →（可选）电度召唤。
- 接收 I 帧校验 N(S)，序号错误立即断开；每 w 个 I 帧或 t2 到期发送 S 帧；对端确认超出已发范围视为协议错误。
- 发送窗口达 k 时等待确认，t1 内未确认断开；空闲 t3 发 TESTFR，t1 内未确认断开。
- 断开后由采集引擎 1s→30s 退避重连，重连后重新 STARTDT 与总召唤。

## 命令（接入现场控制闭环）

写入只能经控制闭环（权限、限值、双人复核、审计、回读）。驱动内部：

1. SBO：发送 S/E=1（选择）→ 等待 ACTCON。否定确认 →“命令未执行”；超时 → 发送撤销（DEACT）并报告“命令未执行”。
2. 发送 S/E=0（执行）→ 等待 ACTCON。否定 →“未执行”；超时 →“结果未知”。
3. `waitActTerm`：等待 ACTTERM，超时 →“已确认执行但未收到激活终止，结果未知”。
4. 同一命令 IOA 同时只允许一个命令；不自动重发。
5. 控制闭环随后读取反馈 IOA 的缓存值作为回读；工艺到位确认请使用控制闭环的反馈确认配置。

注意：控制闭环的总命令超时为 `Scada:CommandTimeoutMs`（默认 5000ms），SBO + ACTTERM 最多需要 3 次确认等待，请据设备超时调整。

## 不支持 / 限制

- 带时标命令（58～64）、参数加载（110～113）、文件传输、读命令（102）、复位进程（105）、测试命令（104/107）。
- 冗余连接组（多链路主备切换）、TLS（IEC 62351）。
- 非默认 ASDU 参数长度（COT 1 字节、CA 1 字节、IOA 2 字节）。
- 测试使用自研子站模拟器；**未与真实 RTU/保护装置或第三方测试工具（如 QTester104）互操作验证**。
