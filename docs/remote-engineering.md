# 网关远程工程操作

设备配置页面沿用“测试连接 / 读取预览”“OPC UA 变量浏览”和“采集诊断”。设备分配到网关后，这些操作在该网关执行，连接地址和串口均以网关主机为准。测试可用于已停用、尚无测点的设备，便于先浏览再导入；重连仍要求存在可运行的采集任务。

## 证书与导入

“OPC UA 证书”增加“证书作用范围”：中心本机或某台远程 OPC 设备所属的网关。网关 PKI 独立于中心，信任或撤销会影响同一网关全部 OPC UA 设备。先发起测试或浏览，让未知服务器证书进入该网关待信任列表；核对 SHA-256 后信任。客户端公钥从所选位置下载，私钥不提供下载。服务器仍须信任该客户端公钥，网关不自动降低安全模式。

页面切换范围会清空旧列表并取消旧查询。请求带预期网关编号，中心在排入请求时再次校验；设备已迁移则拒绝，不能将原确认改投另一网关。所选设备删除或移回中心时要求重新选择。

浏览游标保留在实际采集进程，绑定用户、设备、配置版本和父节点；每个进程最多 64 个、每用户最多 8 个，空闲 5 分钟过期。完成、关闭、配置切换和信任变更会释放相应会话。导入预览在中心保存，应用时先从网关重新读取元数据，再在中心事务中检查权限、设备配置、名称和类型，批量原子创建测点。等待远程响应期间不持有中心数据库写事务。

## 在线请求的边界

- 需要网关在线、租约有效且确认当前配置。双方通过 `engineering-v1` 协商能力；旧网关明确提示升级，采集和补传继续使用既有协议。
- 测试读取允许管理员和操作员，其余工程操作仅管理员。中心在请求创建、领取和回执时检查当前账户权限；请求绑定原网关、会话和配置，变化后结果被拒绝。
- 全中心最多 16 个在途请求，每网关及每用户最多 4 个。请求期限为设备超时加 5 秒，限制在 10～65 秒；实际驱动另受设备超时限制。请求参数最多 8 MiB，响应最多 16 MiB；详细诊断在网关分页，导出仍包含全设备测点。
- 网关每次运行一个工程请求。回执丢失时只重传原结果，在途请求不会再次执行。用户取消或期限、会话、配置、权限变化后取消工作；配置切换和退出要等实际 I/O 完成，再停止或替换旧采集实例。

这是在线工程 RPC，请求与结果不跨中心或网关重启持久保存，也不离线积压后自动执行。请求超时、断线或取消，不能据此断定证书修改尚未发生；先刷新实际证书库或诊断状态。重连的 202 表示网关接受请求，实际重连见后续诊断事件。信任、撤销和重连在中心先记录请求审计，再记录回执或结果未确认。

详细诊断返回网关编号及实际配置摘要，导出不含网关密钥、OPC 密码或私钥。诊断统计和浏览游标属于运行实例，重建后重新开始，不属于持久运维指标或完整诊断包。

## 接口

普通工程接口保持原设备路径。证书增加设备范围接口：

| 方法与路径 | 行为 |
|---|---|
| `GET /api/devices/{id}/opc/certificates?gatewayId={gateway}` | 所属网关证书列表 |
| `GET /api/devices/{id}/opc/certificates/{sha256}/public?gatewayId={gateway}` | 该位置客户端公钥 DER |
| `POST/DELETE /api/devices/{id}/opc/certificates/{sha256}/trust?gatewayId={gateway}` | 信任/撤销服务器证书 |
| `GET /api/gateway-agent/engineering?active={requestId}` | 认证网关领取或检查在途请求 |
| `POST /api/gateway-agent/engineering-results` | 提交原请求回执，返回相同编号确认 |

证书响应带 `X-Scada-Acquisition-Scope`，工程响应禁止缓存。既有 `/api/opc/certificates` 始终管理中心本机。

远程工程操作属于第 3 项的阶段交付。[网关设备离线报警](gateway-device-alarms.md) 已接入中心状态与页面；网关管理界面、服务安装、真实硬件、长稳、规模和故障验收继续按 [完整网关范围](remote-gateway.md) 推进。
