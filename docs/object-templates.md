# 设备对象与模板

管理员进入“组态配置 → 设备对象与模板”。模板定义一类设备的测点、报警和操作面板；对象实例将模板应用到某个采集设备及一组地址。

## 模板与版本

点击“新建模板”，从可修改的水泵示例开始。示例地址是结构示例，需按现场 PLC 的地址表、信号类型和控制约定修改。

- 测点逻辑键如 `run`、`frequency`，用于版本之间匹配同一个测点；名称是显示名称。逻辑键只接受英文字母开头的字母、数字、下划线及短横线，最多 64 字符。
- 每个测点配置区域、地址偏移、类型、倍率、偏移量、单位、量程、可写状态和归档策略。实际数值地址 = 实例基址 + 模板地址偏移。
- 报警使用逻辑键绑定模板测点，可配置限值、变位、等级、延时和恢复死区。
- 面板模板复用工艺组态编辑器，按逻辑键绑定输入及控制测点。模板中不保存现场测点编号，实例化时会分配实际编号。
- “保存模板”仅更新草稿；“发布新版本”创建不可修改的发布快照。已有版本不随草稿变化，实例也不自动升级。
- “发布历史”可以查看每个版本的测点及面板。删除仍有实例关联的模板会被拒绝。

单个模板最多 500 个测点、2000 条报警、1000 个面板图元。发布时检查测点类型、地址范围、逻辑键、报警引用、面板绑定、控制值和导航目标。

## 批量生成

选择已发布版本，点击“批量生成对象”，配置采集设备、名称前缀、起始编号、数量、起始基址和地址间距。

例如前缀 `P`、起始编号 1、数量 3、基址 100、间距 10，会生成 `P01`、`P02`、`P03`，基址分别为 100、110、120。模板测点偏移 2 对应地址 102、112、122。测点名称加上实例名称前缀，如 `P01.频率`，避免同一采集设备下的命名冲突。

每次支持 1～100 个对象。先预览，再确认生成；任何对象存在地址越界、缺失设备、名称冲突或绑定错误时，整个批次不修改配置。生成操作在一个数据库事务中完成，并记录操作人。

生成的面板均为草稿。在“对象实例 → 面板草稿”检查数据绑定、控制动作和权限后，通过画面编辑器发布。实例化本身不下发设备命令。

## 升级与本地覆盖

发布新版本后，在“对象实例”选择一个对象，或选择同一模板的多个对象，点击“预览升级”。每次最多升级 100 个对象。

系统比较三个状态：上次生成的模板基线、当前现场配置、新版模板生成的配置。

- 现场未修改的字段采用新版模板。
- 仅现场修改、模板未改动的字段保留现场值。
- 双方都修改为不同值的字段须选择“保留现场”或“采用模板”，再重新预览。
- 新增模板测点、报警和面板绑定会生成对应配置。
- 本地已经删除的模板成员需要明确选择重新生成。
- 模板移除成员时，须选择保留为独立配置或删除。保留后该成员不再受模板跟踪。
- 仍被草稿、已发布画面或保留报警引用的测点不能删除。可先保留测点，发布新面板后再管理旧配置。
- 删除报警规则时关闭其活动报警记录，历史记录保留。
- 面板草稿采用整体三方比较；若现场和模板均修改了面板，需明确选择保留本地面板或采用模板面板。

字段选择产生不兼容组合时，校验会拒绝应用，可通过“重置处理选择”重新决策。预览后的配置变化会使预览失效，必须重新预览；整个批次存在未解决冲突时，不会部分升级。

升级更新测点与报警配置，面板变化写入草稿。已经发布的运行面板保持原版本，待检查并发布后切换。

## 解除关联

“解除关联”只移除模板跟踪记录，保留测点、报警、历史和面板。解除后这些配置可独立管理，不再接收模板升级。仍有关联对象的采集设备和对象面板不能直接删除。

## 验证

- `dotnet test Scada.sln -c Release`：包含模板验证、批量原子性、三方合并、过期预览、成员重建、删除引用保护、运行面板隔离、成员改名及 100 对象批次。
- 在 `web` 中执行 `npm run test:e2e`：验证模板版本、角色限制、批量接口，以及面板编辑、快捷键保存、批量生成和冲突处理的浏览器流程。

模板现支持 Modbus TCP/RTU、S7 和 OPC UA 地址族；实例基址分别以寄存器/线圈地址或字节为单位，S7 另设 DB 编号和位偏移。OPC UA 测点配置 NodeId，可用 `{instance}` 代入实例名称、`{address}` 代入基址加地址偏移，详见 `protocols.md`。单个模板不能混用地址族。示例泵模板仍为 Modbus 地址，不能直接用于 S7 或 OPC UA 设备。表达式和高级运行功能按 `product-roadmap.md` 继续推进。
