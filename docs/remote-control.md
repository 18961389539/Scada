# 网关远程命令与回执

当前远程命令从实时测点写值、已发布画面控制动作进入同一中心状态机。中心先持久保存请求及审计，再由网关预留、在线领取授权、落盘开始状态、调用实际采集驱动并保存回执。没有入站网关控制端口，不把远程设备交给中心本机的驱动执行。

## 操作与查询

实时监视页面点击“写值”，确认目标值后下发。远程命令返回编号及回执；页面保留编号，提供“查询回执”。运行画面的控制动作也展示远程命令回执。

“写入及回读已确认”表示同一测点写后回读匹配，不能据此证明电机、阀门等设备已完成实际动作。设备许可、模式及独立动作反馈仍在第 7 项范围。

出现请求异常或“结果未知”时，保留原编号并查询后续回执。系统不会自动创建一个新编号重发；同一编号也不能改目标值。新的现场操作应在确认设备状态后显式发起。

## API

普通操作账户使用原有用户 JWT；网关身份不能调用这些操作接口：

```http
POST /api/commands
Content-Type: application/json

{"tagId":123,"value":61,"requestId":"8768cb80-2f13-4d19-bf07-e148a5b66982"}
```

返回 `success`、`message`、`readBack`、远程 `commandId` 和 `outcome`。`requestId` 为非空 GUID，同一次请求或网络重试必须复用同一编号、账户、测点和数值。不同内容或账户复用编号会被拒绝。旧客户端可不提供编号，但每次调用会生成新命令，不能依赖它实现请求重试去重。

`GET /api/commands/{commandId}` 返回该命令的持久状态、数值、创建/截止时间和最终回执。操作员只能查询自己的命令，管理员可查询所有命令；查询不会再次执行。接口不返回网关密钥、会话或执行令牌。该查询目前只覆盖远程命令，本地控制的完整持久状态随第 7 项继续实现。

画面控制接口 `POST /api/screens/{screenId}/actions/{nodeId}` 同时接受 `publishedRevision` 和 `requestId`；目标测点及数值仍取自服务端已发布画面。预览不能控制，过期的画面版本不能下发。

网关在自己的当前会话内调用：

| 接口 | 行为 |
|---|---|
| `GET /api/gateway-agent/commands` | 领取至多一条属于当前会话的命令；重复领取内容不变 |
| `POST /api/gateway-agent/commands/{id}/authorize` | 再次检查条件，持久提交后返回本命令的短期执行授权；期限内重试返回同一授权 |
| `POST /api/gateway-agent/command-results` | 提交安装数据流、命令编号、执行令牌及结果；中心提交后才确认 |

以上接口沿用独立网关 HTTPS 身份和 `X-Scada-Session`。执行令牌不能作为用户登录或另一条命令的授权，不进入普通日志。

## 执行条件和期限

受理和执行授权均要求设备启用、测点可写且数值合法、网关当前租约有效、最近心跳和设备采样状态可用、当前配置已被该网关确认。授权时再次读取数据库，检查设备归属、配置版本和操作账户启用/角色；旧会话不能取得新授权。

中心期限为 `Gateway:CommandTimeoutMs`，默认 10000 毫秒，允许 100～120000 毫秒；每个网关最多 100 条未终结请求。网关按服务端时间及单调时钟扣除完整往返耗时，不能用本机时钟偏差延长授权。授权期限与本地采集引擎 `GatewayAgent:CommandTimeoutMs` 共同约束排队和执行。

在线状态依据租约及最近观测，不能瞬时判断尚未收到的新网络故障。已经受理的命令仍须在原会话和期限内取得授权；未授权请求过期后不会在连接恢复时补执行。数据可离线积压补传，控制命令不采用这种执行策略。

收到配置变化、身份/会话拒绝或停止请求后，网关取消在途命令并等待原采集 I/O 退出，不能提前确认替代配置。已授出的短期授权与已经进入设备的动作不能被通信撤权追溯撤销；此时按实际可证的回执记录结果，不能宣称设备没有动作。

## 持久状态

| 中心状态 | 含义 |
|---|---|
| `Queued` | 已持久受理，尚未领取 |
| `Reserved` | 已提供给网关，尚未授出执行授权 |
| `Authorized` | 已持久授出执行授权，等待网关回执 |
| `Completed` | 已取得确认、失败或未下发的终态 |
| `Unknown` | 不能确定执行结果；不会因此重新执行 |

网关先把不可变命令写入自己的日志，再请求在线授权；有效授权受保护地落盘为 `Started` 后才进入驱动。相同命令 ID 不能第二次从预留进入开始。配置、会话或期限不匹配的授权不会进入驱动；本地命令日志满时不领取执行授权，返回未下发，保留已有记录。

授权前取消/重启归为未下发；开始状态已保存但没有最终结果时，重启归为未知。执行结果保留到中心明确确认；确认丢失只重发原回执，不重发物理写入。已确认且过期超过 7 天的本地日志可清理，未确认回执不能被覆盖。

中心超时或会话结束时，未授权命令归为未下发，已经授权的命令归为未知。相同安装数据流的新进程可在自己的新会话中提交旧命令的持久结果；它不能重新执行旧会话命令。中心暂时生成的未知状态可由后续经过校验的持久回执更新；已经确认的回执内容不能改写。

当前驱动没有提供足以证明执行失败的结果时，远程命令保守记录为未知，不能把连接失败、丢确认或回读失败描述为设备肯定未动作。

## Modbus TCP 修复与验证

实际 TCP 计数测试发现原有底层客户端在 PLC 写确认丢失后会自动重发。现已移除该依赖，使用有界、可取消且不重试的直接 TCP 交换，验证 MBAP 事务号、协议、站号、长度、功能码、读取字节数及写响应地址/值或数量。写后回读和四种字节序仍由既有采集引擎及编码器处理。

真实独立网关和生产中心 API 的 TCP 场景覆盖倍率反算/回读、同编号重复调用、画面动作复用编号、浏览器下发/查询、执行授权响应持续丢失、回执确认丢失、断网过期、PLC 写确认丢失及执行中进程强制结束/重启。对每一步统计实际写报文，验证没有额外物理写入。单元测试另覆盖伪造/过期授权、账户和配置变化、旧会话、中心重建、取消、迟到回执及错误响应。

这些证据来自本机模拟链路。其余协议的控制互操作、真实 PLC/串口、满盘/掉电、长期运行和规模仍需现场验收；设备独立执行反馈、区域权限和完整操作工作流仍按既定路线推进。
