# 协议与接入

第 3 项仍在实施。当前代码包含 Modbus TCP、Modbus RTU 和 Siemens S7；OPC UA、在线变量浏览、导入预览、完整采集诊断及远程采集网关尚未完成。不能将本阶段视为第 3 项整体验收通过。

## 设备配置

在“配置 → 设备配置”选择协议。协议不同，显示对应的连接参数。

| 协议 | 连接参数 | 测点地址 |
|---|---|---|
| Modbus TCP | 主机、端口（通常 502）、站号、字节序 | Coil、DiscreteInput、HoldingRegister、InputRegister；从 0 开始的报文地址 |
| Modbus RTU | 串口、波特率、8 个数据位、校验、停止位、站号、字节序 | 与 Modbus TCP 相同；站号 1～247，不发送广播 |
| Siemens S7 | 主机、端口（通常 102）、CPU、机架、插槽 | DB、M、I、Q；从 0 开始的字节偏移，Bool 另设位偏移 0～7 |

RTU 串口填写服务端的端口名称，如 `COM3` 或 `/dev/ttyUSB0`，并确保服务进程有访问权限。同一物理串口的轮询、控制和连接测试共用仲裁，逐个执行。每次交换在仲裁内打开、关闭端口，并保留 RTU 帧间静默时间；这会产生一定开关端口开销。同一串口的启用设备须使用相同通信参数、不同站号。总线排队时间计入超时，排队中已超时的请求不会打开串口或发送命令。

S7 当前支持 S7-200、300、400、1200、1500 的绝对地址访问。S7-1200/1500 的相应 DB 需要允许绝对地址访问、关闭优化块访问并启用 PUT/GET；具体权限和硬件支持按 PLC 手册及现场配置确认。S7 使用固定大端字节序，不使用 Modbus 字节序选项。输入区 I 只读。开关量通过 S7 原生位写入，避免覆盖相邻位。

例如 `DB17.DBX100.6` 配置为：区域 `DataBlock`、DB 编号 `17`、地址 `100`、数据类型 `Bool`、位偏移 `6`。`DB17.DBD104` 的 REAL 配置为地址 `104`、类型 `Float`、位偏移 `0`。数值类型仍为 Bool、Int16、UInt16、Int32、UInt32、Float、Double；本阶段未加入字符串、数组或结构体。

## 测点、模板和 Excel

- 保存测点时同时检查所属设备的协议，禁止 S7 区域与 Modbus 设备混用。
- 设备已有测点时，切换协议必须与全部已有地址兼容；否则拒绝保存，避免运行配置被静默解释成另一种协议。
- 对象模板支持 S7 区域、DB 编号及位偏移。实例基址和相对偏移的单位随协议变化：Modbus 为寄存器/线圈地址，S7 为字节。模板成员必须属于同一协议地址族，实例化及升级再次校验目标设备。
- Excel 在原 15 列后增加“DB编号”“位偏移”。旧 15 列 Modbus 文件仍可导入，缺省 DB 编号为 1、位偏移为 0。导出再导入保留 S7 地址。非法行跳过，已有测点不受该行影响。
- “测试连接 / 读取预览”可指定区域、地址、类型，以及 S7 的 DB 和位偏移；结果是原始值，未进行工程量缩放。

## 异常处理和验证边界

RTU 校验站号、功能码、字节数、CRC、异常响应及写入回执。S7 检查 PLC 返回状态，读取失败时报告区域及地址。两种新增驱动不自动重发控制写入；命令由现有队列执行、按工程量反算并回读。开始执行后超时可能已经改变现场状态，操作端须按“结果未知”处理。

数据库迁移保留已有 Modbus 设备、测点、画面和模板，补充新字段默认值。CPU 的枚举零值 S7-200 和插槽 0 可正常保存。

本地自动验证包含：RTU 报文与分片响应、错误 CRC/站号/功能码/长度、异常码、写入回执、广播拒绝、总线串行化、过期请求不发送；真实 TCP 上的 S7 握手、按字节分组读取、浮点及整数、原生位写入保留相邻位、PLC 错误、超时后重连；旧库迁移和 Excel 新旧格式。

这些测试使用协议仿真和串口连接替身。尚未用真实 RS-485 总线或物理 PLC 做现场验收，也不证明全部 CPU 型号、操作系统串口驱动或现场规模均已验证。

实现参考：[Modbus 官方规范入口](https://www.modbus.org/modbus-specifications)、[S7.Net Plus](https://github.com/S7NetPlus/s7netplus)。S7 驱动依赖 S7netplus 0.20.0，串口运行库为 System.IO.Ports 10.0.0。
