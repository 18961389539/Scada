# 协议与接入

第 3 项仍在实施。当前代码包含 Modbus TCP、Modbus RTU、Siemens S7 和 OPC UA，以及 OPC UA 在线变量浏览、导入预览和采集诊断。远程采集网关和真实设备验收尚未完成，不能将本阶段视为第 3 项整体验收通过。采集状态、读取分组、逐点质量、事件、重连和导出说明见 `collector-diagnostics.md`。

分配到网关的设备已接入远程测试读取、OPC 浏览/导入、证书管理及详细诊断，操作发生在所属网关。证书作用范围、在线确认和超时后核查方式见 [远程工程操作](remote-engineering.md)。

## 设备配置

在“配置 → 设备配置”选择协议。协议不同，显示对应的连接参数。

| 协议 | 连接参数 | 测点地址 |
|---|---|---|
| Modbus TCP | 主机、端口（通常 502）、站号、字节序 | Coil、DiscreteInput、HoldingRegister、InputRegister；从 0 开始的报文地址 |
| Modbus RTU | 串口、波特率、8 个数据位、校验、停止位、站号、字节序 | 与 Modbus TCP 相同；站号 1～247，不发送广播 |
| Siemens S7 | 主机、端口（通常 102）、CPU、机架、插槽 | DB、M、I、Q；从 0 开始的字节偏移，Bool 另设位偏移 0～7 |
| OPC UA | `opc.tcp` 端点 URL、安全模式、安全策略、可选用户名密码 | `OpcNode` 区域及完整 NodeId；不使用寄存器地址、站号或字节序 |

RTU 串口填写服务端的端口名称，如 `COM3` 或 `/dev/ttyUSB0`，并确保服务进程有访问权限。同一物理串口的轮询、控制和连接测试共用仲裁，逐个执行。每次交换在仲裁内打开、关闭端口，并保留 RTU 帧间静默时间；这会产生一定开关端口开销。同一串口的启用设备须使用相同通信参数、不同站号。总线排队时间计入超时，排队中已超时的请求不会打开串口或发送命令。

S7 当前支持 S7-200、300、400、1200、1500 的绝对地址访问。S7-1200/1500 的相应 DB 需要允许绝对地址访问、关闭优化块访问并启用 PUT/GET；具体权限和硬件支持按 PLC 手册及现场配置确认。S7 使用固定大端字节序，不使用 Modbus 字节序选项。输入区 I 只读。开关量通过 S7 原生位写入，避免覆盖相邻位。

例如 `DB17.DBX100.6` 配置为：区域 `DataBlock`、DB 编号 `17`、地址 `100`、数据类型 `Bool`、位偏移 `6`。`DB17.DBD104` 的 REAL 配置为地址 `104`、类型 `Float`、位偏移 `0`。数值类型仍为 Bool、Int16、UInt16、Int32、UInt32、Float、Double；本阶段未加入字符串、数组或结构体。

## OPC UA 接入与证书

默认使用 `SignAndEncrypt` 和 `Basic256Sha256`，也可明确选择签名模式或两种 AES 策略。端点必须实际提供所选模式和策略，连接不会自动降级。`None` 只允许匿名身份；用户名密码身份要求 `SignAndEncrypt`。

1. 保存 OPC UA 设备，点击“浏览变量”或使用有效 NodeId 测试读取。首次安全连接遇到未信任服务器证书时会失败。
2. 打开“OPC UA 证书”，在“待信任”中核对证书主题、有效期和 SHA-256 指纹，与服务器管理端确认后再点击信任。
3. 在“客户端公钥”下载 DER 公钥证书，将其加入服务器信任库。下载接口不提供私钥。
4. 重新发起连接。撤销信任会关闭已建立的 OPC 会话、使浏览与导入预览失效，并触发采集重新连接。

密码使用 ASP.NET Core Data Protection 保护后存入配置库，接口仅返回 `hasOpcPassword`，不返回明文或密文。编辑时密码框保持空白，留空保存保留原密码，勾选“清除密码”才会清除。密钥保存在配置数据库目录下的 `keys/`；Windows 使用当前服务账户的 DPAPI 保护。客户端证书及信任库默认在同目录的 `opc-pki/`，也可通过 `Scada:OpcPkiRoot` 指定。

**现有自动备份只备份配置数据库，尚未包含这些密钥、证书和历史库。** 迁移时必须保护并处理这些目录；Windows 更换主机或服务账户后，复制密钥文件不保证可以解密，可能需要重新录入密码并建立证书信任。完整备份恢复按第 11 项实施。

NodeId 可使用 `ns=2;s=Boiler.Temperature`、数字、GUID、字节串标识，或 `nsu=urn:plant:variables;s=Boiler.Temperature`。推荐命名空间 URI 形式，避免服务器命名空间索引变化造成地址错配。当前采用轮询读取，每批最多 100 个变量，支持上述 7 种精确匹配的标量类型；字符串、数组、结构体、64 位整数及方法调用不在本次范围内。

坏质量、Uncertain、类型不符和非有限数值会单独标记该点，不能作为正常零值发布；实时数据保留服务器源时间戳和错误信息。单点失败不将其他正常点一并标坏，整个会话或服务调用失败才触发设备断线处理。控制写入不自动重发，回读质量无效时返回“结果未知”。

## OPC UA 变量浏览与导入

设备行点击“浏览变量”，沿对象目录浏览，选择变量后修改测点名称，再“预览导入”。默认创建只读测点，只有明确勾选并且服务器身份拥有写权限时才能创建可写测点。不支持的类型和不可读变量会显示原因。

- 浏览页大小为 1～200，界面默认 100；继续分页复用服务器会话及 continuation point。游标绑定管理员、设备和当前目录，空闲 5 分钟过期，关闭界面释放会话。全局最多 64 个浏览会话，每个管理员最多 8 个。
- 单次导入 1～500 个变量。预览检查重复名称、重复节点、类型和访问权限，10 分钟过期，绑定发起管理员及设备配置。全局最多保留 128 个预览。
- 确认时重新核对连接配置、名称及服务器元数据，在一个数据库事务中创建全部测点并记录操作。配置或元数据变化、任何一行错误均拒绝整个批次；成功后预览失效。
- 浏览、导入和证书管理仅管理员可用。节点浏览不自动修改项目配置。

## 测点、模板和 Excel

- 保存测点时同时检查所属设备的协议，禁止 S7 区域与 Modbus 设备混用。
- 设备已有测点时，切换协议必须与全部已有地址兼容；否则拒绝保存，避免运行配置被静默解释成另一种协议。
- 对象模板支持 S7 区域、DB 编号、位偏移及 OPC NodeId。实例基址和相对偏移的单位随协议变化：Modbus 为寄存器/线圈地址，S7 为字节。OPC NodeId 可使用 `{instance}`（实例名称）、`{address}`（基址加偏移）占位符；数值基址仍限制在 0～65535。模板成员必须属于同一协议地址族，实例化及升级再次校验目标设备。
- Excel 在原 15 列后增加“DB编号”“位偏移”“NodeId”，共 18 列。旧 15 列和 17 列文件仍可导入，缺省 DB 编号为 1、位偏移为 0、NodeId 为空。导出再导入保留 S7 和 OPC 地址。非法行跳过，已有测点不受该行影响。
- “测试连接 / 读取预览”可指定区域、地址、类型，S7 的 DB 和位偏移，或 OPC NodeId；结果是原始值，未进行工程量缩放。连接成功但点质量异常时仍显示读取错误。

## 异常处理和验证边界

RTU 校验站号、功能码、字节数、CRC、异常响应及写入回执。S7 检查 PLC 返回状态，读取失败时报告区域及地址。两种新增驱动不自动重发控制写入；命令由现有队列执行、按工程量反算并回读。开始执行后超时可能已经改变现场状态，操作端须按“结果未知”处理。

数据库迁移保留已有 Modbus 设备、测点、画面和模板，补充新字段默认值。CPU 的枚举零值 S7-200 和插槽 0 可正常保存。

本地自动验证包含：RTU 报文与分片响应、错误 CRC/站号/功能码/长度、异常码、写入回执、广播拒绝、总线串行化、过期请求不发送；真实 TCP 上的 S7 握手、按字节分组读取、浮点及整数、原生位写入保留相邻位、PLC 错误、超时后重连；旧库迁移和 Excel 新旧格式。

这些测试使用协议仿真和串口连接替身。尚未用真实 RS-485 总线或物理 PLC 做现场验收，也不证明全部 CPU 型号、操作系统串口驱动或现场规模均已验证。

OPC 自动验证启动真正的 OPC Foundation SDK 服务器，通过 TCP 测试读取、写入、坏节点、源时间戳、分页、元数据、证书信任及撤销、用户名密码认证，以及导入权限、原子拒绝和过期预览。浏览器测试覆盖选点、命名、预览创建和密码保留/清除。尚未完成第三方服务器互操作、长期断网恢复及规模验收。

## 本地 OPC UA 模拟器

执行 `dotnet run --project tools/Scada.OpcSimulator -- --endpoint opc.tcp://localhost:4841/ScadaSimulator`。工具提供 `Scada` 目录下可写的 Temperature（Float）、Run（Bool），只读 Pressure（Double）、110 个 UInt16 寄存器，以及用于验证不支持类型的 Model（String）。通过浏览发现节点，不必手工猜测 NodeId。

这是开发测试工具，包含固定测试账户 `operator` / `opc-test-password`。默认拒绝未信任客户端；测试启动器使用的 `--accept-test-clients=true` 仅用于本地自动测试。工具不作为现场 OPC 服务器部署。

实现参考：[Modbus 官方规范入口](https://www.modbus.org/modbus-specifications)、[S7.Net Plus](https://github.com/S7NetPlus/s7netplus)、[OPC Foundation .NET SDK](https://github.com/OPCFoundation/UA-.NETStandard)。S7 驱动依赖 S7netplus 0.20.0，串口运行库为 System.IO.Ports 10.0.0，OPC UA 客户端及测试服务器 SDK 为 2.0.1。
