# 移动端适配

- **响应式外壳**：宽度 ≤768px（或 ≤1024px 的触屏）时隐藏侧栏，改为顶部汉堡按钮 + 抽屉菜单；页眉精简；对话框占满 96% 宽；触屏下按钮/输入/菜单项最小 40–48px 点击区域。
- **画面运行**：手机上默认"适应"缩放（按屏幕宽度等比），双指捏合缩放（0.2–4 倍），单指原生滚动/平移。
- **控制**：手机上的控制与桌面走同一闭环（服务端预检查 → 确认 → 双人复核 → 下发回读）。所有请求带 `X-Scada-Client: mobile`，服务端中间件按配置拒绝：

```json
"Mobile": { "AllowControl": true, "ControlRoles": [] }
```

  `AllowControl=false` 时手机端只能监视；`ControlRoles` 非空（如 `["Admin","Operator"]`）时仅这些角色可在手机上控制。被拒请求返回 403 并写审计。前端通过 `GET /api/client-policy` 获知结果，显示"手机端只读"并在本地拦截。
- **PWA**：提供 `manifest.webmanifest` 与图标，可"添加到主屏幕"以全屏方式打开；未注册 Service Worker（SCADA 数据须实时，不做离线缓存）。
- **安全说明**：移动端标识由客户端声明（基于屏幕尺寸），伪造请求头即可绕过，属于纵深防御；授权仍以用户区域权限为准。
