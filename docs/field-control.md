# 现场操作控制闭环（路线图第 7 项）

入口：左侧菜单“现场操作”（`/control`，需要 Control 权限），接口前缀 `/api/control`。实时监视写值、运行画面控制按钮、顺控步骤、计算脚本写测点都经过同一个 `ControlCommandService.SubmitAsync`，没有旁路。

## 一次下发的完整流程

1. **控制权**：设备处于“就地”（现场接管）时拒绝一切中心下发，包括画面、顺控和脚本。没有记录即“远程”。切换需要该设备区域的 Control 权限和原因，写差分审计。
2. **挂牌**：设备或测点上有“禁止操作”牌时拒绝任何人。有“检修中”牌时只允许挂牌人本人操作，便于检修调试。摘牌由挂牌人完成；挂牌人不在时，由该区域的配置管理员代摘。挂牌和摘牌都必须写明原因，记录永久保留。
3. **基础校验**：包括测点量程、数据类型和寄存器反算（原有逻辑）。
4. **控制策略**（`ControlPoint`，按测点配置；未配置的测点只做第 3 步和回读）：
   - 限幅 `LimitMin/LimitMax`：比测点量程更严的操作范围。
   - 单次变化上限 `MaxStep`：按当前实时值计算；当前值无效时拒绝，因为无法判断变化量。
   - 许可/互锁条件 `PermitExpression`：受限数值表达式（与计算测点同一引擎，`#测点编号` 引用），结果非 0 才允许。引用的测点质量不好时视为不满足。拒绝原因会写出 `PermitMessage` 和不成立的条件。
5. **操作确认**：界面先调 `/control/check` 预检查，确认框里展示当前值→目标值、限幅、控制权、挂牌和全部拒绝原因；有拒绝原因时确认按钮不可用。策略要求确认（`RequireConfirm`）时，接口请求必须带 `confirmed=true`，防止绕过界面直接调用。
6. **双人复核**（`DualApproval`）：
   - 发起后生成待复核请求（`ControlRequest`），不下发；有效期 30～3600 秒，超时作废。
   - 必须由另一位对该测点有 Control 权限的用户批准，本人不能批准自己的请求，只能撤回。
   - 批准时重新执行第 1～4 步检查（例如申请之后挂了牌，就不执行），状态先改为已执行再下发，避免两人同时批准导致重复下发。
   - 审计里记录申请人与复核人。
   - 计算脚本等自动化写入不能写需要复核的测点。
7. **下发与回读**：沿用原有路径，串行写入并读回同一测点，比对编码后的原始值；本地采集和网关远程命令都适用。超时或连接中断判为“结果未知”，不会自动重发。
8. **独立反馈**：策略配置了 `FeedbackExpression` 时，回读成功后在 `FeedbackTimeoutMs` 内轮询实时值等待条件成立（例如阀位反馈 ≥ 95%）。超时判为失败，结果为“未知”（`Unknown`），因为写入已到设备但工艺没有到位。
9. **审计**：每一次拒绝、待复核、批准/驳回/撤回/超时、下发结果、反馈超时都写入操作日志。记录包含测点、旧值→新值，详情里有来源（实时监视、画面名与图元、顺控名与步骤、计算脚本）、是否确认、复核人和命令编号。

## 预置批量操作 / 顺控

- 顺控（`ControlSequence`）属于一个区域，包含 1～50 步。每步写一个测点的值，可选“完成条件”表达式、超时和写后延时。
- 保存需要顺控所在区域和每个步骤测点的 Configure 权限。执行需要所在区域和每个步骤测点的 Control 权限，并且必须确认。
- 执行在后台逐步进行，每一步都走上面的完整流程，再在超时内等待该步完成条件为真：
  - 任一步被拒、失败或条件超时，顺控立即停止，其余步骤记为“跳过”。
  - 可以中止，当前步骤结束后停止。
  - 每步的状态、消息和起止时间都持久保存在 `ControlSequenceRun` 中。
- 勾选双人复核的顺控，启动时生成复核请求，另一人批准后才开始执行，执行人仍记为申请人。步骤测点如果要求双人复核，所在顺控本身也必须设为双人复核，否则这一步会被拒绝。
- 服务重启时，仍在运行的顺控会被标记为“中断”，不会自动续跑，以免重启后对现场重复动作。

## 权限

| 操作 | 需要 |
|---|---|
| 预检查、下发、画面控制 | 测点所在区域 Control |
| 配置控制策略 | 测点所在区域 Configure |
| 就地/远程切换、挂牌 | 设备或测点所在区域 Control |
| 摘牌 | 挂牌人本人（Control），或该区域 Configure |
| 批准/驳回 | 测点所在区域 Control（顺控：区域及全部步骤测点的 Control），且不是申请人 |
| 编辑顺控 | 区域及全部步骤测点 Configure |
| 执行/中止顺控 | 区域（及全部步骤测点）Control |

列表接口按 View 权限过滤。越权请求返回 403，并写拒绝审计。

## 已知限制

- 控制策略、挂牌和顺控尚未纳入工程包导出/导入与配置快照。
- 互锁只在中心侧判定，不能替代 PLC 内的安全联锁。就地/远程状态由人工切换，暂不支持从现场开关量自动同步（可以把现场开关写进许可条件来实现同样的拒绝效果）。
- 没有配方管理；顺控是线性步骤，不支持分支、并行和失败后的回退步骤。
- 反馈等待依赖实时缓存的刷新周期，判定精度受采集周期限制。
