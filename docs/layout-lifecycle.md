# 运行布局的草稿、发布与回退

报警横幅始终固定在运行页顶部，不再作为可拖动的网格区域。打开旧布局编辑时，会在本次草稿中移除旧横幅区域，并按运行页的相同规则回收顶部连续的横幅专用行；非顶部横幅移除后保留原有内容区域位置。页面会显示转换提示，只有保存并发布才影响运行版本。旧发布版本与历史记录仍可正常运行和预览。

每个显示器可设置目标浏览器窗口宽高，默认 1920×1080；该尺寸随草稿、发布版和工程包保存，仅用于预览，不会限制现场窗口大小。编辑器和发布/历史审阅中均可打开“运行效果预览”，在所选分辨率中复用运行页展示已发布画面、工具栏、固定报警条及报警列表。预览禁止交互和控制；切换查看分辨率不改动保存的目标尺寸。画面内容使用当前已发布版本，历史布局预览不会恢复历史画面版本。

工作站保存接口也会拒绝绑定未发布的布局。已有未发布绑定不会自动删除，编辑时需先发布布局、改选已发布布局或清除绑定；清除后可正常保存工作站。

布局列表的缩略图明确展示草稿结构，可按草稿名称或发布名称搜索，并组合发布状态、工作站使用情况筛选。点击工作站数量可查看工位名称、说明、本机标记和控制权限；读取工位失败时使用情况显示为未知，使用筛选暂时禁用。本机摘要显示实际分配的发布名称和版本，只有本机登记有效、分配布局已发布且读取成功时，才可直接进入本机运行。

“更多”菜单包含复制布局、版本历史和删除。复制布局会生成独立的新草稿，自动避开已有名称，需另行发布才能分配。编辑器也支持复制显示器，保留区域配置和目标尺寸。模板提供双屏总览/详情、单屏全屏、导航与画面、画面与报警、左右双画面五种结构；可先展开查看，套用需确认且支持撤销。属性区显示区域占内容网格的宽高比例。

编辑器提供区域复制、粘贴及快速复制。复制内容保留类型、画面绑定、标题和尺寸，可切换到同一布局的其他显示器后粘贴；粘贴自动生成当前显示器内唯一的区域编号，并按行寻找可容纳原尺寸的空位，不挤占已有区域。无可用空位、目标网格过小或达到 16 个区域时禁止粘贴。剪贴板仅在当前编辑会话内使用。复制粘贴、删除和显示器前移/后移均可撤销、重做，排序后保留当前显示器与区域选择。显示器顺序决定运行页的显示器编号，须保存并发布后生效。

快捷键支持 Ctrl/⌘+S 保存草稿、Ctrl/⌘+C/V 复制/粘贴区域、Ctrl/⌘+D 快速复制、Delete/Backspace 删除区域，以及 Ctrl/⌘+Z、Ctrl/⌘+Shift+Z 或 Ctrl/⌘+Y 撤销/重做。输入框保留文本编辑快捷键，保存快捷键同样遵循校验、保存中防重及版本冲突保护；每个显示器至少保留一个区域。

手机端的布局和工作站列表以卡片展示，布局卡片保留发布状态、草稿缩略图、更新时间和操作菜单，并可展开查看关联工位与控制权限；工作站卡片保留发布布局名称、本机标记、权限及编辑、设为本机、删除入口。搜索与筛选规则与桌面一致，切换屏幕尺寸保留筛选条件，工位读取失败仍显示未知状态。

手机编辑器以画布为首屏重点，保留名称、撤销/重做和运行效果预览，布局模板、显示器参数及区域属性默认折叠；横屏、竖屏保持目标宽高比。点击校验问题会切换显示器、展开对应属性并定位字段。桌面仍直接展示设置与属性。

画布下的“几何调整工具”支持当前区域左/右/顶/底对齐和水平/垂直居中，目标位置越界或与其他区域重叠时禁用。左右/上下均分按区域列表顺序铺满当前显示器，不能整除的余格优先分给前面的区域；区域数量超过对应行列数时禁用。适配网格按原网格或区域范围缩放边界，冲突时尝试放入空位；无法安放全部区域时禁用，不删除任何区域。所有操作保留区域类型、标题及画面绑定，只修改当前显示器的几何数据，并作为一次撤销步骤。

修改行列数导致区域越界时，会先列出受影响区域并展示适配预览。可取消、适配全部区域后修改，或保留原区域位置作为未完成草稿；保留位置时仍需修正越界问题后才能发布。没有区域受影响时直接修改网格。

在“组态配置 → 运行布局”中编辑布局并选择“保存草稿”。草稿可以暂缺画面、存在重叠或越界，校验提示会保留；保存草稿不会改变工作站正在使用的布局。

未保存的布局编辑在停止修改约 400 毫秒后按当前账号暂存到本浏览器，刷新和关闭窗口前也会尝试写入。重新进入列表可选择恢复或删除暂存，恢复本身不写服务器。恢复已有布局时重新读取服务器草稿；版本号或内容不同、原布局已删除时，需确认恢复为独立新草稿，避免覆盖他人修改。新建布局同样可以恢复。成功保存或确认放弃编辑会清理对应暂存；读取服务器失败时保留原暂存，浏览器存储损坏或空间不足时提示手动保存。各编辑会话单独存储，账号之间相互隔离；清除浏览器数据会清除本地暂存。

关闭编辑器后，从列表选择“发布”，审阅已保存草稿与当前发布版的差异，填写发布说明并确认。发布会重新检查区域编号、网格边界、重叠及画面的发布状态，检查通过后生成新的发布版本。工作站只能选择已发布布局；运行页面发现新版本后提示更新，由操作员确认应用。

发布与回退审阅同时展示分配给该布局的工位、说明、本机标记、控制权限、当前发布版本和读取时间。此信息不能说明工位此刻实际应用的版本，系统尚无工位应用版本回传。读取分配失败时暂停提交，可单独刷新且保留发布说明。提交前重新读取分配，若工位或控制权限变化，先更新影响范围并保留说明，需核对后再次提交；不会自动重试发布或回退。

“版本历史”记录每次发布的内容、操作人、时间和说明，支持查看历史布局以及与草稿、当前发布版比较。回退必须填写说明，并会重新校验历史版本引用的画面。回退生成一个版本号更高的新发布版本，保留当前已保存草稿；历史记录不被覆盖。保存、发布或回退时遇到并发修改会拒绝操作，需重新加载后审阅再提交。

发布和历史审阅提供变更摘要及逐项明细；画面绑定显示当前可读取的画面名称和 ID。显示器优先按唯一名称、再按结构匹配，最后尝试原位置，减少移除前一显示器带来的连锁差异；区域优先按标识匹配，再按完全相同的其余字段识别纯改名。缺少稳定身份时只能进行上述推断，同时修改标识和其他属性仍可能显示为移除、新增；重复或空标识的草稿区域也会逐项保留。

升级前已有布局会自动保留为已发布布局，并建立历史记录。工程包分别保存草稿与发布快照；导入旧版仅含 `document` 的布局时兼容为草稿和发布版。发布历史保留在本机，工程包导入的发布内容发生变化时会追加导入记录。工作站绑定仍为现场本地配置，不随工程包迁移。

删除布局须提交列表中审阅过的 `revision`。工作站修改须提交 `expectedUpdatedTs`，删除须提交 `updatedTs`，均与当前记录严格匹配；缺失或过期返回 409。工作站更新时间使用单调递增值，并作为数据库并发标记，避免同毫秒更新或时钟回拨绕过校验，无需新增数据库列。删除布局清除工作站分配时也更新该标记。冲突后界面保留编辑内容并禁止直接重试保存，重新加载后须核对分配和控制权限；删除冲突提供列表重新加载入口。
