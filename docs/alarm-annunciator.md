# 报警声光联动

喇叭、灯塔与浏览器提示音随活动未确认报警的最高等级变化；消音、确认、暂挂、抑制、恢复都会刷新输出。

## 面板与输出

- **声光面板**（`AnnunciatorPanel`）：可按区域或全局；锁存/跟随；消音默认时长；闪烁亮/灭毫秒（危急可单独更短）；是否驱动浏览器声音。
- **输出**（`AnnunciatorOutput`）：喇叭、闪光灯、灯塔红/黄/蓝/绿，各绑定一个**可写物理测点**（含 MQTT / Sparkplug / Modbus 等驱动映射的写点）。激活/复位值可配。
- **等级映射**（`AnnunciatorLevelMap`）：每个等级决定喇叭/灯塔通道、是否闪烁、浏览器音色（`critical` / `warning` / `info`）。未配置时用默认：危急红闪+喇叭、警告黄闪+喇叭、提示蓝常亮无喇叭。

配置入口：左侧「配置 → 声光联动」（`/config/annunciators`）。面板随工程包分区 `annunciatorPanels` 导入导出；消音状态是运行态，不进包。

## 仲裁逻辑

1. 只统计**活动且未确认**、且未暂挂/抑制/抖动的报警。
2. 区域面板只看本区域；全局面板看全部。
3. 取其中最高等级，按映射点亮对应通道；喇叭在消音期内关闭，灯可保持。
4. **跟随**：无驱动报警时全部熄灭。**锁存**：灯保持到操作员消音（或面板删除）；喇叭仍跟随消音。
5. 闪烁由服务端按面板节拍翻转非喇叭通道；喇叭不闪。

## 声光写入路径

输出写入走 `ControlCommandService.SubmitAnnunciatorAsync`：

- **仍检查**：备机拒绝、计算测点拒绝、不可写、设备未启用、就地控制、禁止操作牌；写入后同点回读；写操作日志（来源 `Annunciator`）。
- **跳过**：双人复核、操作确认、限幅、变化率、许可互锁、独立反馈。声光是公共指示输出，不宜挡在复核后面；真正的安全联锁仍应在 PLC 侧。

## 操作

| 操作 | 权限 |
|---|---|
| 查看面板/状态 | 区域 View（全局面板：任一区域 View） |
| 新建/修改/删除 | 区域 Configure（全局面板：全局 Configure） |
| 消音 / 取消消音 / 试验 | 区域 AckAlarm（全局：任一 AckAlarm） |
| 报警页「确认可见」「声光消音」 | AckAlarm |

消音默认 1～120 分钟，到期自动恢复喇叭。报警页「确认可见」批量确认当前用户有权确认的实时未确认报警。

## 浏览器声音

顶栏声音开关（本机记忆）关闭时完全静音。开启时：

- 新报警仍有一次短促提示；
- 若存在已启用且未消音的面板，并给出了 `soundKey`，则按最高等级循环播放，直到消音、静音或无驱动。

音色为 Web Audio 自生成，不依赖外部音频文件。

## 已知限制

- 输出只通过测点写入现场；没有独立的 MQTT 主题字段（把 MQTT/Sparkplug 点配成可写测点即可）。
- 工位/浏览器静音不能替代现场喇叭消音。
- 闪烁精度受服务循环与采集周期限制；未在真实灯塔硬件上验收。
- 试验会短暂点亮全部输出约 1.5 秒后恢复仲裁结果。
