# 计算测点与表达式

## 使用

管理员打开「组态配置 → 计算测点」，填写名称、表达式、计算周期和输入有效期，先「校验并预览」，再保存。预览仅读取当前缓存，不发布结果、不写历史、不触发报警。

用 `#测点ID` 引用输入，例如物理测点 `#12` 的工程量已经包含倍率和偏移，则 `#12 * 2` 直接使用该工程量；不会再应用一次倍率。输入列表同时支持物理测点和其他计算测点。计算测点独立于设备，统一为只读 Double，可在实时监视、趋势、报表、报警规则和工艺画面中选择；现场控制接口拒绝向其写值。

示例：

| 表达式 | 含义 |
|---|---|
| `(#12 + #13) / 2` | 两点平均值 |
| `if(#12 > 80, 1, 0)` | 数值条件，布尔结果为 1/0 |
| `clamp(#12, 0, 100)` | 限制范围 |
| `round(#12 / 1000, 3)` | 换算后保留三位小数，四舍五入时远离零 |
| `if(#12 != 0, #13 / #12, 0)` | 避免执行除零分支 |

支持 `+ - * / % ^`、一元 `+ - !`、比较 `< <= > >= == !=`、逻辑 `&& ||`，以及 `pi/e/true/false`。幂右结合，`2^3^2 = 512`、`-2^2 = -4`。函数包括 `if`、`abs/sqrt/floor/ceil/round`、`min/max/pow/clamp`、`sin/cos/tan/log/exp`，其中 `log` 是自然对数。`if` 和逻辑运算只执行需要的分支；输入质量检查仍覆盖表达式中声明的所有引用。

不支持字符串、对象、文件、网络、反射、循环或任意 C#/JavaScript。表达式最长 4096 字符，最多 512 个语法节点、64 层、64 个输入；函数最多 16 个参数，`round` 小数位为 0～12 的整数。每个项目最多 2000 个计算测点，依赖链最多 64 层。保存时检查全部依赖，并拒绝缺失输入、循环、自引用、非法参数和重名。

## 运行与质量

计算在中心后台按依赖顺序执行，基准扫描为 100ms；单点周期可设为 100～600000ms。这是监控侧周期，实际执行受进程调度影响。计算结果每次扫描均进入实时缓存和总线；历史是否落盘仍由变化/周期归档策略决定。

归档判断同时考虑批次内已接受的最新值和已持久保存的状态，避免多次相同扫描在首次刷盘前重复落库；数值或质量发生变化仍会保留对应记录。数据库和磁盘暂存都失败时，归档状态仍根据实际保留的内存缓冲重建。

输入有效期为 100～3600000ms，以输入当前值的采集/计算时间判断。输入必须存在、数值有限、质量为 Good；物理输入的设备必须启用，计算输入的定义版本须一致。旧于最近配置加载时间、超期或超出当前时间 1 秒的输入不能参与正常计算。任一配置重新加载后，等待新采集/计算确认，避免把旧参数下的值当作新值。

| 情况 | 输出质量 | 值和提示 |
|---|---|---|
| 全部输入有效且运算成功 | Good | 新值，携带定义版本及最早输入的源时间 |
| 停用、输入缺失/非 Good/超期、设备不可用或定义待确认 | Uncertain | 保留上次有限值；没有旧值时为 0，附原因 |
| 除零、溢出、函数定义域或无效配置 | Bad | 保留上次有限值，附错误 |

停用和错误都不会把保留值当作正常值。独立的算术错误不阻断其他计算；历史、报警和实时推送会丢弃配置变更前排队的旧定义结果。历史通过现有持久暂存链路写入；中心停机期间不计算，也不根据补传历史自动回算。计算值的源时间用于追踪最早输入，链式输入的新鲜度按该输入的计算时间判断，工程师应按来源更新速度配置各级输入有效期。

## 修改、删除与迁移

每次修改递增定义版本。编辑和删除须携带读取时的版本；版本冲突返回 409，页面保留草稿，需明确重新读取后核对。读取失败或离开页面时取消未完成请求，保存期间禁止改表单，也不会自动重发失败的保存。审计保存操作者、完整前后定义和结果。

被计算引用的输入测点不能删除；设备删除和模板升级删点同样检查依赖，数据库外键提供并发保护。删除计算测点会关闭该点未结束的报警并保留历史，若仍被其他计算引用则拒绝删除。当前画面引用沿用已有画面发布校验；删除后应重新校验相关工程画面。

测点 Excel 导出保留原前 18 列并增加第 19 列「测点ID」；存在计算定义时增加「计算测点」工作表。导入通过原编号映射到目标库实际编号，支持目标库编号不同的迁移；所有被引用输入须包含在工作簿中，不按目标库同号测点猜测绑定。含计算定义的工作簿整体校验、整体提交，任一行错误则全部回滚。原有不含计算工作表的物理测点导入仍支持逐行有效导入。

配置库迁移 `AddCalculatedTags` 保留旧测点编号、倍率、报警及画面。存在计算测点时拒绝降级到不支持它们的数据库结构；必须先处理定义，不能把无设备计算点强制转成物理点。完整备份/还原包含表达式、版本与依赖表；运行时缓存重启后重新计算。

## 第 4 项剩余范围

累计量、运行小时、能耗积分（含持久状态、间断质量与重启处理）以及受限定时脚本已作为“计算任务”实现，见 `calc-jobs.md`；派生测点可作为计算测点的输入。事件触发脚本仍未实现。500～5000 点规模、并发工程编辑、中心长稳和实机故障验证仍需验收。
