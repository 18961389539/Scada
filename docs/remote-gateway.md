# 远程采集网关：实施范围与阶段记录

第 3 项仍在实施。当前已有网关本地存储、命令恢复和遥测上送组件，以及采集循环的持久记录接口；**还没有可部署的完整网关进程、中心接收服务或网关管理界面**。不能把组件测试通过视为远程网关已经交付，也没有改变第 4～11 项的范围。

## 已实现的持久队列

`Scada.Gateway` 当前是库项目。`GatewayAgentStore` 为网关安装生成并持久保存 `StreamId` 和全局递增序号，使用独立 SQLite 文件，不复用中心配置数据库。

- 采集批次包含设备 ID、配置版本摘要、工程量、质量、采集时间及可选源时间。单批最多 5000 点，拒绝重复测点 ID、非法质量、非有限数值等无效内容。错误文本截断为最多 1000 字符，不因诊断文本过长而丢弃测量。
- 采用 WAL、每连接 `synchronous=FULL` 及显式写事务，包内容、序号和积压计数一起提交。每次访问独立打开连接，多个设备并发写入仍按事务分配连续序号。
- 队列同时保存精确 JSON 和 SHA-256；重试发送同一份内容。读取发现校验不符时停止发送，不自行删除或重建队列。
- 只有数据流和队首序号均匹配的确认才删除该包；重复确认幂等，越过队首或错误数据流的确认被拒绝。确认后重新打开存储，序号继续递增。
- 待发送 JSON 默认限额 256 MiB，满时拒绝追加，不裁掉旧数据。该限额是待发送包的 UTF-8 字节数，不是 SQLite 数据库、空闲页、WAL、命令日志及配置的总磁盘限额。具体离线容量仍需按点数、周期和变化量测算。
- 使用数据库应用标识及版本检查，拒绝误指向已有其他数据库或不受支持的版本，不自动覆盖旧文件。错误或损坏的数据不会通过自动清空来“恢复”。

`GatewayTelemetryUploader` 每次尝试只发送队首包，在得到匹配确认前保留本地记录。它使用正常的系统 HTTPS 证书验证，不自动跟随重定向；只有明确启用测试选项时才允许回环 HTTP。身份、会话及包摘要放在请求头，地址不允许携带用户名、密码、查询参数或片段。响应读取也受超时和 4 KiB 确认大小限制。

目前 HTTP 测试使用测试服务器，**生产中心的 `/api/gateway-agent/telemetry` 接口尚未注册**。组件中的会话标识还没有形成中心端的授权与隔离机制。

SQLite 提交设置依据官方 [WAL 说明](https://www.sqlite.org/wal.html)及 [synchronous 说明](https://www2.sqlite.org/pragma.html)。这些设置加强提交持久性；实际存储设备、操作系统和掉电行为仍需验收，不能据此宣称绝对不丢数据。

## 与采集循环的连接

`ICollectorJournal` 是可选的批次持久记录接口，`GatewayCollectorJournal` 将配置版本固定到当前采集运行实例。

- 正常读取先计算完整工程量批次，等待持久提交，再更新实时缓存并发布。持久记录尚未完成时不提前发布正常样本。
- 通信故障也形成带原因的质量批次，便于之后补传。持久队列满或持续无法写入时，诊断明确显示任务异常暂停；缓存标记通信故障，已保存队列保留。网关监督进程的自动恢复仍待接入。
- 控制写入及回读后也尝试持久记录；记录失败返回“写入已发送、持久记录失败”，不重复下发物理写入。它不能将本来已发出的命令描述为从未执行。

现有中心采集进程没有注册该接口，保持原来的历史流程；这次改动**没有完成第 6 项的中心历史持久缓冲**。

## 本地命令日志

命令以不可变 ID、设备/测点、工程值、配置版本及截止时间保存。重复 ID 内容变化被拒绝，同一命令只能从 Reserved 成功进入 Started 一次，终态结果不能被重复请求覆盖。

执行授权令牌和离线配置的存储接口接收调用方已经保护的内容，生产调用方仍须接入持久密钥及 Data Protection；网关配置传输模型中的 OPC 密码只能在受认证 HTTPS 通道中使用，不可写入普通日志。

恢复必须持有当前安装目录的独占文件租约，不能只凭 PID、锁文件内容或历史状态判断旧进程已经停止。恢复将 Reserved 归类为未下发，将 Started 归类为结果未知；二者都不重新开始执行。结果保留到中心确认，已确认且已过期至少 7 天的记录才可清理。命令日志默认上限 100000 条，满时拒绝新命令，不覆盖旧记录。

本地状态机解决的是进程内/本地重开恢复约束。中心命令领取、授权响应丢失、旧会话隔离、实际执行与回执对账仍必须按上表完成后才能交付远程控制。

## 当前验证与下一步

25 项网关自动测试包含文件重开恢复、连续序号、容量与确认、完整性检查、并发写入、过期/重复命令、命令恢复、独占文件租约、受保护配置、错误数据库保护，以及实际采集任务的提交先后顺序、队列满与写后记录失败。真实 HTTP 测试覆盖接受数据后连接断开、同包重传、503、错误确认、超时和禁止重定向。

标准 .NET 全套 138 项通过，24 项既有接口/浏览器回归及前后端构建通过。尚未完成独立网关进程崩溃/重启、生产中心接收与配置同步、端到端历史补传、现场、长期运行或规模验收。

下一阶段继续贯通中心身份及会话、持久收件箱和配置分配，再接入独立网关运行进程、控制路由、远程工程操作和管理界面。每项仍按本页完整要求验收。
