# 导航与找功能

侧栏、命令面板与总览快捷入口共用 `web/src/nav/catalog.ts` 一份目录（路径、标题键、关键词键、权限、图标）。

## 命令面板

- 快捷键：`Ctrl+K`（macOS 为 `⌘K`）；顶栏搜索按钮；总览「搜索页面」亦可打开。
- 按标题、路径、中英别名模糊匹配；`Enter` 跳转，`Esc` 关闭；↑↓ 选择。
- 最近访问、收藏按用户名存在本机 `localStorage`（`scada_nav_recent_*` / `scada_nav_fav_*`）。
- 可见性与侧栏一致：`hasAny` / `hasGlobal`。

## 侧栏筛选

侧栏顶部输入框按标题/关键词过滤菜单项；组态子菜单在有筛选时自动展开。

## 总览快捷入口

保留原有 KPI；增加常用入口卡片、收藏与最近访问。权限不足的入口不显示。
