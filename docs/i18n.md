# 多语言（zh-CN / en-US）

- 前端：vue-i18n（MIT）。文案以中文为源，`web/src/i18n/locales/zh-CN.json` 由 `npm run i18n:extract`（scripts/i18n-extract.py）从源码抽取并替换为 `$t()`/`tr()`，键为 `文件名.k哈希`；英文在 `en-US.json`。`npm run i18n:check` 检查缺译、占位符不一致、未知键与残留中文字面量（Playwright i18n.spec 也会运行）。需保留中文的行（如匹配服务端结果文本）标 `i18n-ignore`。
- 切换：页眉用户菜单 / 登录页。偏好按用户保存在服务端（`PUT /api/auth/me/locale`，登录时下发），本机缓存于 localStorage；切换后整页重载（Element Plus 语言、模块级文案同步）。默认中文，不跟随浏览器语言。
- 后端：请求头 `X-Scada-Locale`（其次 Accept-Language）。英文时中间件翻译 /api JSON 响应的 message/title/detail/error 字段（对照表 `src/Scada.Server/Localization/messages.en-US.json`，支持插值、前缀、分号拼接）；未收录则保留中文。LocalizationTests 检查 Endpoints/Auth/Control/Models/Projects 中的用户提示全部有译文。
- 报表：即席导出表头按请求语言；归档报表按 `Scada:ReportLocale`（默认 zh-CN，归档后不可变）。
- HMI：图元 `texts['en-US']`（设计器"English 文字"），运行时按界面语言显示，缺省回退中文。
- 限制：审计日志、采集驱动/网关诊断等后端内部文本仍为中文。
