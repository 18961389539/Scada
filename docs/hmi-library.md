# 图库与参数化模板

“组态配置 → 图库与模板”。

## 内置 ISA-101 符号

- 26 个自研绘制的 SVG 符号（泵/压缩机、阀门、电机/风机/搅拌器、储罐/换热器/过滤器、管道/弯头/三通、皮带/螺旋输送机、变送器/液位计/流量计、指示灯/状态条/声光报警器），未使用任何厂商素材。
- 风格遵循 ISA-101 “灰度为主”：线条为中性灰，填充色表示状态——停止 `#6b7580`（中灰）、运行 `#e9edf1`（亮灰白）、报警 `#e03131`（红，闪烁；系统“减少动态效果”时不闪）、数据无效/过期 `#3d4650`（暗灰）。
- 画面图元类型 `symbol`，字段 `symbol` 为符号键（`isa:pump`、`user:自定义键`）。`tagId` 决定运行/停止，新增的可选 `alarmTagId` 值 ≥ 0.5 时显示报警色。

## 用户符号

- “导入 SVG 符号”可多选文件。浏览器端只保留静态图形元素（path、rect、circle、text、渐变等），移除脚本、事件属性、style、外部链接与图片；服务端再次拒绝 `<script>`、`foreignObject`、`image`、`use`、`style`、事件属性、`javascript:` 与外部 `url()`/`href`。
- SVG 中用 `currentColor` 的部分会随状态变色。

## 参数化模板（面板）

- 在画面编辑器选中若干图元 → “存为模板”：图元按包围盒归一化，所选图元上的具体测点（输入、报警、控制输出）替换为占位符（同一测点同一占位符），可勾选“用模板实例替换所选图元”。
- 画面中的模板实例（类型 `template`）只保存 `templateKey` 与 `bindings: [{ key, tagId }]`。渲染与服务端都按同一规则展开（`ScreenExpander`）：内部图元编号为 `实例--内部`，按实例框缩放。
- **一处修改全部生效**：在图库页编辑模板（复用画面设计器，占位符显示为可绑定的“测点”）并保存后，所有画面——包括已发布画面——的实例立即使用新模板，保存结果会列出受影响的画面。
- 模板内的控制按钮只能使用占位符；运行时点击 `实例--内部` 图元，服务端读取已发布画面的实例绑定与当前模板，解析出输出测点和值，再走完整控制闭环（控制权、挂牌、限幅、许可、确认、双人复核、回读反馈、审计）。
- 画面校验/发布时检查：模板存在、所有占位符已绑定、绑定测点存在、模板内控制输出可写且命令值合法、用户符号存在。被画面或模板引用的图库项不能删除或改键。
- 模板不能嵌套模板。每个模板最多 200 个图元、50 个占位符。

## 导入导出与工程包

- “导出图库”下载 `scada-hmi-library.json`（用户符号与模板）；“导入图库”按键新增或覆盖，整批校验。
- 工程包新增全局分区 `hmiLibrary`（按键），配置快照与回滚自动包含。为保持旧快照内容哈希不变，该分区为空时不计入哈希。画面中新增字段为空时不序列化，旧画面与旧工程包逐字不变；`alarmTagId` 在工程包中写作 `alarmTagRef`。

## 已知限制 / 待决策

- 模板修改即时作用于已发布画面（不经画面重新发布）。如需“模板也要发布/审批后才生效”，可增加模板版本与发布流程。
- 嵌入式的设备对象模板面板可以使用符号，但不能使用图库模板实例。
