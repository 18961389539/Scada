## 第 1 项交付记录（2026-10-24）

- 实现 12 类图元、属性与测点绑定、多选移动、对齐、尺寸调整、图层、复制粘贴及撤销重做。
- 草稿与发布内容分离保存于配置数据库，带增量迁移、乐观并发检查、发布前引用检查、删除保护及操作审计。
- 发布画面支持 SignalR、快照补读、质量过期提示、导航、嵌套弹窗及服务端限定的控制动作。预览可查看目标草稿，但不能执行控制。
- 新建演示数据库生成可编辑的锅炉总览。水位改用独立寄存器 22/23，避免与频率 5/6 重叠；不自动重写已有项目地址。
- 使用方式见 `screens.md`。

验证：标准 `dotnet test Scada.sln -c Release` 共 61 项通过；`npm run test:e2e` 前端构建及 6 项接口/浏览器场景通过。测试覆盖旧库升级保留设备、示例绑定校验、草稿隔离、发布版本、引用保护、权限、拖拽/尺寸/复制/撤销/保存重开、离开保护、预览、导航弹窗和无效质量显示。截图已进行视觉检查。

## 第 3 项阶段记录（2026-10-24）

- 增加 Modbus RTU 和 Siemens S7 驱动及协议路由，设备页面显示串口或 CPU/机架/插槽配置；连接测试支持对应地址。
- RTU 共用物理串口仲裁，轮询、控制及测试按帧串行执行，队列超时不发送；验证 CRC、响应站号、功能码、数量、异常及写入回执。
- S7 支持 DB/M/I/Q、字节与位地址、按区和 DB 分组读取、原生位写入及数值写入，输入区只读。
- 测点、模板、实例化/升级、Excel 导入统一检查协议和地址。Excel 增加 DB/位字段，保留旧格式兼容；修复被跳过的非法导入行仍可能修改已有实体的问题，以及 16 位 BADC 回读未换序的问题。
- 新迁移保留旧配置，正确保存 CPU/插槽零值。使用方式和验证边界见 `protocols.md`。
- OPC UA、在线变量浏览、导入预览、完整采集诊断和远程采集网关仍待实施；RTU/S7 仍需真实硬件验收。

阶段验证：标准 `dotnet test Scada.sln -c Release` 共 91 项通过（采集 43、引擎 45、服务端 3）；`npm run test:e2e` 前端生产构建、标准后端构建及 15 项接口/浏览器场景通过。新增真实 TCP 上的 S7 协议仿真、RTU 报文/总线仲裁测试、Excel 新旧格式与非法行隔离、S7 模板实例化及升级、配置页面操作。S7 与 RTU 配置截图已检查。标准构建仍有原有 7 条传递依赖兼容警告，未屏蔽。
