## 第 11 项运维与高可用（2026-10-25）

- 主备：`HaCoordinator` 心跳、文件目录仲裁租约（比较并交换、任期）、主机续租失败自我隔离、备机过期 + 时钟偏差余量后接管；无仲裁时只允许人工/强制接管，网络恢复后按任期/节点名消解双主。`INodeRole` 贯穿采集、控制、计算、聚合、报表、通知、备份，备机全部不执行；`HaStandbyMiddleware` 对网关与非 GET 接口返回 503 并给出主机地址。
- 复制：配置库在线备份快照 + SHA256 去重 + 迁移重载；历史库按 rowid 增量；交接前最终同步。不采用 Litestream（Windows、动态分库、checkpoint 冲突）。
- 切换：主机发起手动切换、备机人工接管（主机在线转交，否则需仲裁确认或强制），自动接管；均写操作日志与节点事件。网关 `FailoverServerUrls` 轮换，中心对每条流接受一次序号接续并审计。
- 备份：`BackupScheduler` 完整备份 → 自动恢复演练 → 可插拔异地目标（目录、S3 SigV4）上传核对与各自保留 → 本地保留（最近 N 份 + 天数）；运行记录与健康告警。
- 监控与自恢复：`/metrics`（Prometheus，令牌或系统权限），覆盖采集延迟、通信错误、报警、发件箱、历史暂存、磁盘、主备、备份、循环心跳；日志按天/大小滚动与保留；看门狗发现关键循环停滞后退出由 systemd/SCM 拉起。
- 部署：`tools/deployment/server/` 下 systemd 单元与 install/upgrade/rollback 脚本、Windows 服务 Install/Upgrade/Rollback 脚本（releases + current 链接、升级前配置库快照、健康门、失败自动回滚），程序支持 `UseSystemd` 与 `--SiteSettings`。
- 前端“运维与高可用”页面（系统权限）：主备状态/事件、切换与接管（填写原因，强制二次确认）、备份记录、立即备份并演练、单包演练；备机顶部常驻“备机（只读）”标识。
- 测试：两进程主备集成测试（选主、复制、只读、手动切换、杀主自动接管、重启回备、无双主）；备份流水线（演练、目录/S3 假服务、保留、失败不上传）、SigV4 向量、指标鉴权、备机门控（采集/控制/网关序号）、网关轮换；浏览器场景 1 项。
- 未完成：跨机/跨网段与 SMB 仲裁实测、systemd/SCM 提权安装与自动回滚实测、仲裁目录单点、长时间复制性能。

## 第 7 项现场操作控制闭环（2026-10-25）

- 实时监视、运行画面、顺控与计算脚本统一走 `ControlCommandService.SubmitAsync`：就地/远程 → 挂牌（禁止操作/检修中）→ 量程与类型 → 限幅、单次变化率 → 许可/互锁表达式 → 操作确认 → 双人复核 → 下发同点回读 → 独立反馈表达式等待（超时判失败）。
- 双人复核由另一位有区域控制权限的用户批准，批准时重新检查，状态先占位防重复执行；超时作废。
- 顺控：线性步骤、每步完成条件与超时，失败即停、其余跳过，可中止；重启后标记中断不续跑；可要求双人复核。
- 新增“现场操作”页面（待复核、挂牌、控制权、顺控、控制策略）与通用控制确认框；全部区域授权与审计。说明见 `field-control.md`。
