## 运维监控记录（2026-10-24）

- `SystemWatch`：每 30 秒评估可用磁盘、历史暂存积压与实时总线积压，超阈值写日志并在状态变化时记录一次；`/health` 返回 `warnings[]` 且状态转 `degraded`，首次请求即计算，不依赖首个周期。阈值由 `Scada:DiskFreeWarnGb`、`Scada:HistorySpoolWarnBytes`、`Scada:BusBacklogWarn` 控制。
- 总线丢弃按“本次检查新增”告警，累计值仅展示：否则一次瞬时抖动会让 `degraded` 永久挂住，掩盖后续问题。
- 定时全量备份：维护任务每 24 小时检查一次最新完整包时间，超过 `Scada:FullBackupIntervalHours`（默认 168 小时，0 关闭）就新建；首次启动无包时立即生成。
- CI 增加 `e2e` 作业（windows-latest，`continue-on-error`）：浏览器场景依赖真实 Edge 与 OPC 模拟器，先作观察项，稳定后再改为阻断。
- 诊断包：`POST /api/maintenance/diagnostics` 输出版本与配置计数、健康快照、配置库 `PRAGMA quick_check` 与最近日志；只含计数与状态，不含设备行、口令哈希与密钥；包内保留最近 20 份。说明见 `docs/diagnostics.md`。

阶段验证：`dotnet test Scada.sln -c Release` 共 252 项通过（采集 75、引擎 58、网关 46、服务端 73）；新增 4 项告警测试与 3 项诊断包测试（内容完整性、不含口令哈希/凭据、健康快照反映总线状态）。实测：`DiskFreeWarnGb` 调高后 `/health` 立即 `degraded` + `disk_low`，恢复默认后回到 `ok`；诊断包接口返回 200、603KB，`quick_check=ok`。

## 权限与会话加固记录（2026-10-24）

- 登录失败限速：同一“用户名 + 来源地址”在 5 分钟窗口内失败 5 次即锁定 5 分钟，返回 429 与 `Retry-After`；成功登录清零。计数仅存内存，重启即清空，用于防在线爆破而非跨重启封禁。
- 登录审计：已知账号的失败尝试（密码错误 / 账号停用）与成功登录写入 `OperationLog`；未知用户名只写服务端日志，避免审计表被刷量污染。
- 会话撤销：`SessionRegistry` 在实时连接建立时登记用户、角色与 `credentialsVersion` 快照；管理员改角色、停用、重置密码、删除用户时立即断开该用户全部连接；`SessionReaper` 每 15 秒兜底处理直接改库造成的失效会话。
- 前端：实时连接关闭后重新确认登录态，令牌失效时由既有 401 拦截器统一登出。

阶段验证：`dotnet test Scada.sln -c Release` 共 240 项通过（采集 75、引擎 54、网关 46、服务端 65），失败 0；`npm run build` 通过。尚未实现区域/设备/测点级的资源授权，仍是第 8 项的主体缺口。

## 第 3 项网关控制与回执阶段记录（2026-10-24）

- 中心在下发前持久保存命令、原会话/安装数据流、配置、账户和期限；同编号/同内容重试返回原结果，变更账户或内容不能新增执行。操作员只查询自己的命令，管理员可查询全部，接口不暴露会话或执行令牌。
- 网关先落盘预留，再在线申请有期限的执行授权，保存开始状态后进入实际驱动。授权时重新校验当前配置、设备、可写范围、操作账户及租约；旧会话不能执行新控制，配置切换、撤权和停止会取消在途命令。
- 回执先在网关保存，再提交中心并等待明确确认。丢确认只重传原回执；授权前中断归为未下发，已开始后重启归为未知，不自动执行。中心临时未知状态允许持久迟到回执对账，已确认回执不能改写。
- 实时监视和运行画面均传递命令编号并提供回执查询。请求失败保留原编号；普通本地命令的持久状态、设备许可及独立反馈仍保留在第 7 项范围。
- 实际 TCP 计数发现原客户端在 PLC 写确认丢失后重发了一次。已移除该依赖，改为可取消且不重试的直接收发，校验事务号、协议、站号、长度、功能码和写响应；保持原有编码、工程量和回读逻辑。控制说明见 `remote-control.md`。
