# 采集网关管理

管理员在“组态配置 → 采集网关”管理网关身份、连接、配置确认及设备归属。独立进程的发布、配置和数据保护见 [gateway-deployment.md](gateway-deployment.md)。

## 创建与接入

1. 点击“新建网关”，输入唯一名称。创建后显示一次编号和密钥，可复制密钥或下载 JSON 密钥记录。
2. 密钥默认遮挡；关闭、刷新或离开页面后清除。页面不把网关密钥写入浏览器本地存储。下载的文件包含密钥，须按现场凭据保管。
3. 用 HTTPS 中心地址、编号、密钥和独立数据目录启动网关。列表每 5 秒更新一次，也可关闭自动刷新并手动更新。
4. 查看详情中的进程版本、能力、租约、当前配置摘要和最近确认摘要。中心连接正常仅表示会话有效；具体设备是否在线应看详情中的设备状态。

状态超过 10 秒未更新、读取失败或租约到期时，不继续显示为有效在线状态。待传批数/字节数来自最近心跳；网关离线后保留最后上报值。中心收件箱积压单独展示。未收到过积压报告时显示“未上报”。

## 分配与迁移设备

从网关详情“打开设备配置”进入对应设备列表；在这里新建设备会默认停用，保存后要求再次确认采集位置。取消迁移时，已创建的设备仍保留在中心且保持停用，可在“显示全部设备”找到。

已有设备可在设备列表或网关详情点击“更改采集位置”：

1. 先停用设备，等待原采集任务退出。
2. 原位置是网关时，必须等原网关实际应用并确认包含该设备停用状态的配置。断网或仅租约过期不能证明现场已停止，因此不会解除此条件。
3. 打开或刷新迁移条件，选择中心本机或已启用的目标网关，确认迁移。
4. 设备保持停用。核对目标主机上的网络地址、串口、PLC 和证书后，再到设备配置启用。

保存时中心重新检查条件，并校验读取时的归属和本次停用时间。其他管理员迁移或重新启停后，旧对话框不能覆盖新状态。

## 名称、停用、密钥和会话

- 名称可编辑；启停、轮换密钥和释放会话均需明确确认。页面提交管理版本条件，另一管理员修改状态或现场建立新会话后，旧确认会被拒绝；关闭对话框、刷新核对后再操作。
- 停用或轮换后中心立即拒绝原身份。离线的旧进程恢复联系后才会收到撤权，不能据此认定现场采集已停止。轮换产生的新密钥仍只显示一次，需要到现场更新。
- “释放会话”供已经确认旧进程和现场 I/O 均已停止的情况使用。必须勾选停机确认；释放不会替代现场停机，也不会删除待传数据。
- 请求失败或响应丢失时，操作可能已经提交。页面提示核对实际状态，不自动重发创建、轮换、释放或迁移。密钥响应丢失且无法找回时，核对已有网关，再明确轮换。

管理接口及页面只允许 Admin。列表、详情和设备信息不返回网关密钥、凭据密文或原始会话标识，响应使用 `Cache-Control: no-store`。旧脚本仍可使用原有接口；页面额外发送 `If-Match` 管理版本和迁移源状态条件。

## 本地验收与边界

服务端测试覆盖配置摘要、只读管理查询、管理版本冲突、会话切换、停用确认、设备归属和权限；浏览器测试覆盖一次性密钥、响应丢失、不自动重发、页面离开取消读取与轮询，以及真实独立网关到 OPC UA 模拟器的采集、停用确认和迁移。

迁移场景在停用前必须观测到代理实际拦截的配置轮询，保证待确认中间态确实建立；不使用任意延时推测网关状态。失败时保留有界请求路径和进程诊断，不记录认证头或密钥。修正后连续 4 轮和全量 34 项浏览器/接口场景通过，截图已检查。

补验中另出现过测试工作进程退出和追踪文件丢失，最终独立输出目录下 34 项通过；异常证据及尚未定位的范围见 [maturity-assessment.md](maturity-assessment.md)。
