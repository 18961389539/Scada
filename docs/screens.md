# 工艺画面与可视化组态

管理员进入“工艺画面”并新建画面。查看员和操作员只能访问已发布版本；草稿不会改变运行页面。新建演示数据库时会生成可编辑的锅炉画面。

## 编辑

- 点击左侧图元或拖入画布，支持文字、数值、水泵、阀门、储罐、管道、电机、风机、仪表、按钮、矩形和圆形。
- 拖动移动位置，右下角手柄调整尺寸。Shift 点击多选；支持图层、对齐、复制粘贴、方向键微调、撤销重做。
- 在属性中按“设备 / 测点名称 / 编号”绑定输入测点。设备之间的同名测点以编号区分。
- 设置量程、单位、颜色和激活阈值。运行图元根据有效测点显示数值、液位、颜色、风机和管道动画；质量异常或超过 15 秒没有新采样时显示未知，不把旧值当作当前值。
- 单击动作可配置为导航、画面弹窗或固定控制值。最终联锁与快速控制应由控制器实施。

## 保存、校验与发布

“保存草稿”保存编辑内容；“校验”检查格式、测点、命令值和目标画面；“预览”可读取现场值、浏览目标草稿及弹窗，但不会下发命令。发布时再次校验全部引用，发布成功后运行入口使用新版本。

其他画面需要先发布，才可作为导航或弹窗目标；允许自引用，弹窗最多嵌套三层。删除被已发布画面引用的目标会被拒绝。

两个窗口编辑同一画面时，较旧版本保存返回 409，当前窗口修改仍保留。请保留需要的修改后重新打开最新版本，避免覆盖他人修改。离开或关闭有未保存修改的编辑页时会提示。

运行页通过 SignalR 订阅绑定测点，并定期读取快照以检查数据新鲜度。断线时恢复快照刷新并重连。控制动作须操作员或管理员确认；服务端从已发布图元读取输出测点和值，浏览器不能覆盖命令参数。画面版本已更新时，旧画面下发动作返回 409 并要求刷新。

## 验证

在仓库根目录运行 `dotnet test Scada.sln -c Release`。在 `web` 目录运行 `npm ci` 和 `npm run test:e2e`，浏览器测试使用本机 Microsoft Edge 和独立临时数据库，覆盖草稿隔离、发布引用、并发版本、权限失效以及编辑和运行流程；不会接入现场设备。

当前实现最多每画面 1000 个图元。完整项目打包、设备对象模板及高级运维按 `product-roadmap.md` 的后续条目推进。

## 开发启动

在仓库根目录执行 `dotnet run --project src/Scada.Server`，再在 `web` 目录执行 `npm run dev`，浏览器打开 `http://localhost:5173`。首次开发数据库的账号是 `admin` / `admin123`；演示模式开启时生成锅炉配置及画面。需要模拟实时数据时另行运行 `dotnet run --project tools/Scada.ModbusSimulator`。

生产环境需设置 `Jwt__Key` 并单独完成部署与权限配置；开发启动方式不等同于生产部署验收。
