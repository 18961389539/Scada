# 表单与配置易用性

针对高频组态页（测点、设备、报警规则；计算测点做了轻量加固）统一了校验提示、新建默认值和批量操作。

## 校验

- 对话框内使用 Element Plus 字段规则；必填未填时保存按钮禁用。
- 服务端 400 的 `message` 会尽量映射到对应字段旁（无字段级 errors 时按文案启发式）；无法映射时显示在表单顶部。
- 计算测点仍保留「试算 → 再保存」；名称为空或表达式为空时不可保存。

## 默认值（新建）

| 页面 | 默认 |
| --- | --- |
| 测点 | Float、变化存档、周期 600s、只读；区域随协议切换 |
| 设备 | Modbus TCP `127.0.0.1:502`、站号 1、轮询 1000ms、超时 3000ms、启用 |
| 报警规则 | 高限、警告、触发延时 3s、恢复延时 0、启用 |
| 计算测点 | 启用、周期 1000ms、输入有效期 15s、变化存档 |

对话框顶部有简短说明。测点 / 报警规则 / 设备支持「复制」（名称追加 `_副本`；复制设备默认停用以免误连）。

## 批量操作

无独立批量 API：前端顺序调用单条接口，进度条提示，部分失败时弹窗列出明细（不静默失败）。

| 页面 | 批量能力 |
| --- | --- |
| 测点 | 多选物理测点；批量改存档方式；批量删除 |
| 报警规则 | 多选；批量启用 / 停用；批量删除 |
| 设备 | 多选；批量启用 / 停用；批量删除（有测点的设备会失败并列出） |

共享实现：`web/src/composables/batchRunner.ts`、`formErrors.ts`。

## 限制

- 测点没有启用标志，故无「批量启用」。
- 测点无厂区 `areaId`（区域指寄存器区），故无「批量改厂区」。
- 工位 / 权限仍走原有区域权限；批量删除不可恢复。
